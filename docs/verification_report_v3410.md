## 五之二、交付后修正（用户反馈）

| 反馈 | 根因 | 修复 |
|---|---|---|
| 小箭头显示成小黑块 | 箭头位图按 2× 物理像素绘制（20×20），而 QLabel 固定 10×10 且位图未标 devicePixelRatio ⇒ 只画出左上角一小块；另有 histBody/histArrowObj 两个属性记在标题行、而 setHistoryRowExpanded() 从行上取 ⇒ 箭头 pixmap 从未真正设置 | ① 位图标 devicePixelRatio(2.0)（20×20 物理 = 10×10 逻辑）；② 统一从标题行解析属性；③ 新增自检：44 个箭头逐个检查三角暗像素数与包围盒 |
| 默认展开改成全展开 | 任务书原文是「最新版默认展开」 | 按用户要求改为**全部版本行默认展开**（44/44），并新增断言 |

自检实测：折叠箭头：正常 44 个 / 异常 0 个、默认展开的版本行 = 44 / 44；截图流程收尾也统一还原为「默认全展开」。
