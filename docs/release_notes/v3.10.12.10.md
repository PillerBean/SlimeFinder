# SlimeFinder v3.10.12.10 更新说明

本版本新增**检查更新**功能（未改动搜索/性能逻辑）。

## 新增

- **检查更新对话框**（帮助菜单）：
  - 支持 **GitHub Releases 官方检查**；
  - **自动镜像测速**：官方不可达时，自动对内置的 9 个候选镜像测速（清单响应 + zip 256KB 采样），
    选最快的一个继续检查/下载，用户不需要手动切换；镜像通过仓库内的 `version.json` 清单回退
    （raw 与 release 资产可被这些代理加速）；
  - 下载更新 zip 后用 Release 的 `SHA256SUMS` 校验；下载位置在系统「下载」目录；
  - 支持镜像/官方地址自动回退，失败时给出可读原因；
- **保留蓝奏云网盘源**作为国内手动备用入口（帮助 → 网盘下载页），不对它做自动更新适配。

## 兼容性

- 检查更新使用 Windows 自带的 `curl.exe`，不额外依赖 Qt Network DLL 或 OpenSSL；
- 旧版本升级后默认来源为「自动（官方优先，失败后自动测速镜像）」，可在对话框中切换并记住选择；
- 程序功能、搜索结果与性能相对 3.10.12.9 无变化。

## 发版后需要同步

- 上传 GitHub Release 后运行 `py -3 scripts/gen_version_manifest.py --version 3.10.12.10 --notes-file docs/release_notes/v3.10.12.10.md`，
  并把生成的 `version.json` 提交到 `main`（镜像回退检查依赖它）。
