# SlimeFinder v3.10.12.11（测试版）

## 环形搜索：新增「自动正方形预筛」

环形原来只有「快速抽样」和「精确逐区块」两种：

- 快速：全图等距抽样，有随机抽卡性，可能漏掉孤岛优解；
- 精确：结果可靠，但全图逐区块当前算法约 99 小时，不现实。

本版新增第三种：

### 自动正方形预筛（更稳，较慢）

1. GPU 全图扫描正方形密度（g=15，阈值 0.18）；
2. 按区块间距把高密度窗口分散成种子；
3. 只在种子周围做环形精确精修；
4. 按目标数量和最小间距输出结果。

实测（Java 全图 3,750,001²，RX 6750 GRE）：

- 正方形预筛：**219.6 秒（约 3.7 分钟）**
- 4000 个种子的环形精修：**7 ms**
- 最佳环形覆盖率：**28.58%**
- 当前快速抽样全图最佳：22.2%

2k² 对照：预筛 + 精修得到 21.41%，与环形精确最优完全一致。

说明：

- 该模式需要 GPU；GPU 不可用或预筛失败会自动回退「快速」抽样并提示；
- 预筛期间可以取消；
- 目前全图自动预筛约 3.7 分钟，低于半小时目标，后续还能继续优化。

## 修复

- **最小密度输入为 0 时误切自定义方案**：
  以前输入框还在编辑、焦点没离开时就会触发“已修改”，把方案切到自定义；
  现在只在**焦点离开或回车**后判断修改并切换。
- 环形扫描下拉改为三档：**快速 / 自动正方形预筛（更稳，较慢）/ 精确**。
