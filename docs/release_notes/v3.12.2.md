- 基岩版搜索边界从 ±16,777,216 方块（±1,048,576 区块）
  缩短为 **±2,097,152 方块（±131,072 区块）**；

  再远会降到 0.5 或更差，不再支持；
- Java 版边界不变：±1,875,000 区块（世界边界）。
