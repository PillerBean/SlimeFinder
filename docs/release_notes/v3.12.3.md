# SlimeFinder v3.12.3

## 重要变更

- **更新方式改为手动**：检查到新版本后只显示提示，不再自动下载、不再自动安装。请前往 Releases 下载 `Setup.exe`，核对 SHA256 后手动安装。
- **缓存体系升级**：官方缓存改为 R2 / 网盘 ZIP 分发，缓存包按 8192×8192 区域组织，适合大范围搜索。
- 普通搜索不再写入缓存；基岩版搜索按需读取缓存，搜索逻辑与结果不变。

## 缓存

- 新增官方缓存清单获取：缓存页点击「获取清单」后开始加载，首次打开不再自动请求。
- 清单改为流式加载，边获取边显示，不再一次性建完整列表。
- 支持网盘 ZIP 导入；大文件会显示拉取、检测、导入进度，不再出现长时间无反馈。
- 缓存默认上限改为 10240 MB，可在设置中调整。
- 旧版 1024 缓存包仍可读取；新生成的缓存使用 8192 pack。
- 移除 R2 和网盘页面的「附近」快捷项。
- 缓存页增加按钮防连点间隔，避免重复请求。

## 体验与修复

- 修复大量 ZIP 导入时界面看似卡死的问题。
- 修复缓存列表一次性构建造成的卡顿。
- 更新下载/安装入口已停用；请手动下载 Setup，并核对 `SHA256SUMS`。
- 同步更新中、英、繁体中文语言文本。

## 兼容与注意事项

- 旧缓存仍可读取，但建议重新获取 8192 新缓存以获得更好的大范围搜索体验。
- 首次使用官方缓存前，请在缓存页手动点击「获取清单」。
- 本版没有代码签名，部分杀毒软件可能误报；请只从官方 Releases 下载，并核对 `SHA256SUMS`。
- 自 v3.12.3 起不再自动更新；此前版本介绍中的自动更新说明不再适用。
