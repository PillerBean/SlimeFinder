# SlimeFinder v3.12.3

## 本地缓存新体系

- 仅 Bedrock 使用新缓存；
- 全新格式：zstd + `cache/index.json` + `local/` + `downloaded/` 多包；
- block 128 KiB，pack 约 16 MiB；
- 旧 `.slimecache` 不再读取，只在缓存页提示；
- 下载缓存只读、可整包删除、不可修改内容或大小；
- 本地缓存构建结果写入 v3 local packs；
- 缓存页顶部优先展示下载缓存（本版为空状态）；
- 本地/下载缓存列表支持查看与删除。
