# SlimeFinder v3.13.0

## 搜索性能

- **AMD 显卡默认启用 GPU 图案流式匹配**：
  - 仅方向锁定、单图案变体；
  - 图案判定与匹配在显卡内完成，只回传命中；
  - 实测图案搜索约 **2~6 倍**提速，具体取决于显卡和区域大小。
- NVIDIA / Intel 仍未验证，程序会自动回退 CPU，不会改变结果。
- 设置中仍可手动关闭“GPU 图案流式匹配”。
- 旋转图案保持 CPU 路径；历史实测 GPU 多旋转变体反而更慢。

## 说明

- 本版没有改变搜索判定结果与缓存格式；
- 缓存构建模式、取消、进度与结果排序均沿用原有逻辑；
- 无代码签名，仅提供手动更新；
- 更新前请先退出旧版本，安装后检查 GPU 设置是否符合预期。
