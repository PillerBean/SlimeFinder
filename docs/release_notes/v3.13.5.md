# SlimeFinder v3.13.5

## 搜索性能

- **同区域判定位图复用**：
  - 同一版本、种子、范围内再次搜索时，跳过重复的区块判定；
  - 只重跑匹配阶段，因此改图案、密度阈值、目标数量或排序参数时直接受益；
  - 仅 CPU 精确路径、无缓存搜索启用；
  - GPU 图案/密度流式路径、采样/分层、缓存构建模式保持原逻辑；
  - 单次缓存上限 64M 区块（约 8MB 位图），避免占内存。

实测（CPU 精确路径，同区域第二次搜索）：

```text
Java 图案：
  扫描 0.95 ms → 0.16 ms
  总耗时约 2.36 ms → 1.57 ms

Bedrock 图案：
  扫描 17.4 ms → 1.7 ms

Bedrock 密度：
  扫描 20.2 ms → 3.8 ms
```

命中数、排序与 CPU/GPU 结果保持一致。

## 说明

- 这是内存缓存，不写磁盘，不改变缓存文件格式；
- 换版本、换种子、换范围或开启缓存搜索时不会误用旧位图；
- 无代码签名，仅提供手动更新。
