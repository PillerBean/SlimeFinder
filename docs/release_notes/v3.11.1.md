# SlimeFinder v3.11.1

## 中文（繁体）

- 新增 `assets/i18n/zh-TW.json`，覆盖 1198 个 key；
- 设置页「界面语言」新增「中文（繁体）」；
- 语言切换后重启生效。

## 翻译反馈

- 语言选择旁新增提示：
  「翻译质量不佳？试试联系我们！」
- 点击直接打开「联系我们」。

## 安装器首次启动语言

- 安装程序启动时先选择安装语言（简体中文 / 繁体中文 / English）；
- 安装语言会作为程序首次启动语言写入 `config.json`；
- 安装完成后会显示提示页说明这一点；
- 覆盖更新（`/UPDATE=1`）不会修改已有语言设置。

## 说明

- 英文与繁体中文均使用外部 JSON 语言包；
- 安装包携带 `assets/i18n` 四种文件（zh-CN / zh-TW / en-US / legacy）。
