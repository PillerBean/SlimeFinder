# SlimeFinder v3.13.6

## 搜索性能

- **判定位图复用的适用范围扩展**：
  - 3.13.5 只覆盖精确算法；
  - 3.13.6 同时覆盖 **分层（Layered）** 和 **保守（Brute）**；
  - 采样估算仍不复用，避免采样位图被误当成完整判定。
- 复用条件仍然是：同版本、同种子、同范围、CPU 精确扫描、无缓存，且不超过 64M 区块。

实测（CPU，同区域第二次搜索）：

```text
分层：
  扫描 0.98 ms → 0.20 ms
  总耗时约 6.1 ms → 5.3 ms

保守：
  扫描 0.99 ms → 0.14 ms
  匹配阶段仍占主要耗时
```

命中数、排序与复用时一致。

## 说明

- 这不是缓存格式变更，仍是纯内存位图；
- GPU 流式、缓存构建、采样模式保持原逻辑；
- 无代码签名，仅提供手动更新。
