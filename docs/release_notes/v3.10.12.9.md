# SlimeFinder v3.10.12.9 更新说明

本版本是「开源发布规范化」版本：**程序功能与性能相对 3.10.12.8 无变化**，主要整理文档、许可证与发布流程。

## 变更

- **许可证**：采用 PolyForm Noncommercial 1.0.0（含 Required Notice 署名要求）——
  源码公开、非商业使用；再分发或修改版必须保留版权与 Required Notice，并注明来源；
  商业使用需作者书面授权。新增 `NOTICE` 列出第三方组件（cubiomes MIT / OpenCL-Headers / Qt）。
- **README 重写**：面向新用户精简为「截图 + 下载 + 功能 + 快速开始 + 构建 + 版本规则 + 许可」；
  完整变更历史移至 `docs/update_history.md`，由 `scripts/export_update_history.py` 从更新历史数据自动生成。
- **发布规则统一**：版本号统一四段（如 3.10.12.9）；正式/测试版不再用版本号区分，
  GitHub Release 用手动 `Pre-release` 标记区分，Latest 由未勾选的正式发布决定。
- 新增 `docs/GITHUB_PUBLISH_GUIDE.md` 发布指南与 `scripts/collect_release_assets.ps1` 资产收集脚本。

## 校验

- 单元测试 37 组、参考对拍 117/117、GUI 自检 0 FAIL、审计 CLEAN；
- Windows x64 便携包与安装包均通过打包校验。
