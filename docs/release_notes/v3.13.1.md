# SlimeFinder v3.13.1

## 搜索性能

- **图案 GPU 流式的启用门槛从约 8M 区块降到 16K 区块**：
  - AMD 显卡下，普通小范围图案搜索也能走 GPU 图案流式；
  - 实测 128² / 256² / 512² 范围已有收益；
  - Java 图案小范围约 3~4 倍，Bedrock 约 2~3 倍。
- 仍然只适用于方向锁定的单图案变体；
- 旋转图案、非 AMD 显卡、GPU 不可用、缓存构建模式继续自动回退 CPU。

## 兼容与说明

- 判定结果、结果排序、缓存格式均未改变；
- 图案结果与 CPU 路径逐项一致；
- 无代码签名，仅提供手动更新。
