# SlimeFinder v3.12.0

## 结构工程化

- 新增自包含 `SlimeFinder-Tree-2.0` 文件树；
- 源码按 `app / core / gpu / gui / i18n / utils` 分层：
  - `src/app`：入口与 Windows 资源；
  - `src/gui/mainwindow`：主窗口；
  - `src/gui/dialogs`：对话框；
  - `src/gui/panels`：过程面板；
  - `src/gui/widgets`：可复用控件；
  - `src/gui/services`：更新、遥测等服务；
  - `src/i18n`：语言包与文案 API。
- `tools`、`tests`、`packaging` 分层；
- 自包含构建：`third_party`、`assets`、`tests/reference` 均在新树内；
- 打包脚本加入 `windeployqt`，新树可独立产出可运行安装包；
- GUI 自检实现拆到 `MainWindowSelfTest.inc`，主文件从 13.9k 降到 9.2k 行；
- 旧树冻结保留，未删除任何历史内容。

## 说明

- 本版以结构迁移为主，不改变搜索、匹配、缓存和界面行为；
- 最终发布前需要用户验收。
