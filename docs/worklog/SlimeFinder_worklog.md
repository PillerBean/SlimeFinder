### 已完成的主要语义

- 质量键：密度模式下使用“有效格数量”，不再只按密度百分比。
- 同质化关闭：匹配阶段按有效格数量去重；同一质量只保留最近一个。
- 同质化关闭不扩大候选池；不同质量不足目标 N 时返回不足并提示。
- 同质化开启：允许同质量不同距离，严格按最近 N。
- 忽略阈值：仅密度模式，按有效格数量从高到低取最优；不使用提前停止/智能范围。

- GPU 非精确模式：按距离行带分批匹配，每批整理后继续。
- GPU 精确模式：命中超限回退 CPU，保证最近 N。

## 环形“最优”算法可行性

目标：Java 全图，环形外半径 128 方块 / 内半径 24 方块，最大化环带内有效格数量。

### 现有快路径

1. **撒点抽取 / 粗扫**
   - 区块级粗扫，按 `coarseStep`/`stride` 抽样环心。
   - 取粗分最高的若干候选。
2. **正方形密度预筛 + 精修**
   - 用正方形密度扫描产生种子（`seedCandidates`）。
   - 对种子做 16×16 子偏移环带精修，取 1 格精度结果。
3. **精修/抛光**
   - 区块内 256 个 1 格位置精确算环带交叠。
   - 前若干名在 3×3 区块内再抛光。

结论：现有方法已经是“粗筛 + 局部精算”的两级结构；与卷积方案有重叠，但不是同一件事。

### FFT 卷积可行性实测

测试：CPU numpy，单进程，10% 稀疏场，1 区块 = 1 单元，环带外 8 / 内 2 区块，1024²–8192² 瓦片。

| 瓦片 | 单元数 | FFT 耗时 |
|---:|---:|---:|
| 1024² | 1.0M | 80ms |
| 2048² | 4.2M | 167ms |
| 4096² | 16.8M | 659ms |
| 8192² | 67.1M | 2,958ms |

全 Java 图（3,750,001² 区块）按瓦片外推：

```text
约 150–300 小时 CPU
```

内存：

```text
8192² 瓦片：原始 float32 268MB，FFT 工作区约 1.5–2.5GB，可行
全图 14.06 万亿单元：位图都要约 1.76TB，不可行，必须瓦片流式
```

### 判断

- 全图**区块级**精确 FFT：CPU 约 150h；GPU FFT 估计仍需数小时，未实测。
- 全图**方块级**精确：再乘 256 倍以上，不可行。
- 64 方块粗网格全图约 0.88 万亿单元，CPU 约 10h，GPU 估计 20–40 分钟（估算，未实测）。
- 因此当前 210s 全图结果只能是采样/近似，不是全局精确最优。

### 下一步候选方案

1. **方形密度预筛做上界**，不是只做种子：
   - 外接正方形内有效格总数是环带覆盖的严格上界。
   - 若上界 ≤ 当前最优，整块剪枝。
2. **多分辨率分支定界**：
   - 粗网格上界 → 只细分可能超过当前最优的区域。
   - 叶节点用 1 格环带精算。
3. **FFT/卷积仅用于粗网格候选生成**：
   - 64 方块粗网格，GPU FFT；
   - Top-K 候选回到 1 格精修；
   - 不承诺全局精确，除非加上界剪枝。
4. **对比验证**：
   - 用当前 210s planner 的结果作为基线；
   - 检查粗网格 Top-K 是否覆盖当前最优候选；
   - 若覆盖不了，说明粗粒度或种子策略不够。

### 当前建议

先做“正方形密度上界 + 分支定界”原型，而不是直接上全图 FFT：

- 复用现有 GPU 正方形密度预筛；
- 上界是严格可证明的；
- 有希望在不穷举的前提下保持精确；
- FFT 则更适合作为粗网格候选生成或大规模并行加速。

## 2026-11-18 环形算法评测方法讨论

小范围随机测试无法区分“现有精确路径”和“新全局算法”，因为两者都可能得到同一最优值。需要专门制造可测差距。

### 能测出差距的测试

1. **已知最优的植入场**
   - 在指定环心周围把环带填成史莱姆；
   - 在其他地方放低价值背景；
   - 可放“方形密度高但环形覆盖低”的诱饵区；
   - 全局最优已知，直接测召回与 regret。

2. **针尖场**
   - 超大范围里只放一个高价值环带；
   - 撒点/方形预筛很难抽到；
   - 用来测候选召回，而不是平均分数。

3. **强制近似模式**
   - 小范围本来走精确路径，测不出差距；
   - 强制 `forceCoarse` / 大 `scanStride` / 限制种子，模拟超大范围；
   - 与精确 ground truth 对比。

4. **中等范围精确 ground truth**
   - 例如 1k×1k、2k×2k 方块；
   - 暴力/前缀和算所有环心；
   - 既测结果，也测上界剪枝是否正确。

5. **证明指标**
   - 即使最优值相同，分支定界可以报告“已证明最优”；
   - 记录 `proven`、`gap`、检查节点数、剪枝率；
   - 当前采样法无法给证明，这是可测差异。

### 评测指标

```text
best score / regret
Top-N 集合重合度
候选 recall@M
proven optimal / gap
访问节点数 / 剪枝率
达到当前最优的时间
```

### 算法方向

- 方形密度上界 + 分支定界，优先做。
- 粗网格 FFT 只用于生成候选/上界，不做全图方块级精确卷积。
- 粗网格卷积分数可作为细网格上界；只精修可能超过当前最优的块。
- 最终输出明确标注：`已证明最优` 或 `best-effort，gap=...`。

### 下一步原型

新增 `ring_search_bench`：

```text
ground truth：中等范围暴力或前缀和

```
