## 二、关于「两版 1.18 后群系是否一致」——你的直觉是对的

- 官方 Wiki「World seed」那条「同种子地形与群系一致」**本身带 [verify] 待验证标记**；
- 1.18 时 Mojang 确实做过「seed parity」工作（Bedrock beta 引入了与 Java 一致的世界生成），方向是对的；
- 但两版**浮点精度不同**（Bedrock 大量用 32 位浮点、Java 用 64 位双精度），所以同种子是「高度相似」而不是逐像素一致，差异集中出现在群系边界与地形细节上；
- 所以本项目把基岩版群系定位为**近似上色**，日志措辞已从「一致」改成「按 Java 同种子近似；两版非逐像素一致」。
