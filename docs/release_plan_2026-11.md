# 版本计划更新（2026-11 中旬起）：UI 大改版 + 已批准功能

> 依据：
> * 已批准功能：① 图案旋转优化 + AMD 自动开 GPU 图案流式；② 缓存构建走 GPU（**可选、默认关、保留双路径**）；
>   ③ B1 两级筛选；④ Java 判定内核 2×；⑤ 过程可视化（必须）；⑥ 交互（结果流式/后台预扫描）；**新增：最优候选模式**。

## 一、教训来源：上一轮 UI 大更新踩过的坑（全部有据可查）

| 版本 | 事故 | 根因 | 教训 |
|---|---|---|---|

| v3.6.7/6.8/6.9/6.10 | **折叠按钮位移（连续 4 轮才修好）** | ① 提醒标签被 addWidget 进 QSplitter ⇒ 子项数量/像素分配变化；② 折叠后 QVBoxLayout 把多余空间分给标题行，按钮被垂直居中（跳 70~75px）；③ 用 addStretch 做占位 ⇒ 与地图平分空间，地图只剩一半且分隔条「拉不动」 | 折叠/展开**绝不增删 QSplitter 子项、绝不用 addStretch 争空间**；标题行固定 30px + Fixed 策略；折叠时用「只在折叠时显示的占位控件」；自检断言按钮全局坐标前后完全一致 |

## 四、针对上一轮教训的硬性约束（写进实现自查清单）

1. **禁止 nullptr 进布局**：每个 `new` 后必须立即 `addWidget` 或显式断言；布局重写前后逐项核对 `m_w` 字段（v3.5.5）。
2. **禁止增删 QSplitter 子项做折叠**；折叠只切 `setVisible`，用「折叠时显示的占位控件」代替 addStretch（v3.6.7-3.6.10）。
3. **折叠标题行固定 30px + SizePolicy(Fixed)**；折叠期间钉住分隔条像素尺寸，展开时恢复（v3.6.9）。
4. **数据先于界面**：任何「结果→表格/横幅/日志」刷新，必须先赋值 outcome 再刷新（v3.6.7）。
5. **单一来源**：结果文本/表格/统计/导出共用 `kResultDisplayCap`；方案/冲突文案共用 `explainConflicts()`（v3.6.6）。
6. **布局稳定**：用户拖过分隔条后不再自动改尺寸（v3.6.6）；参数联动去抖 ≥250ms（v3.5.4）。
7. **滚动区高度**：设置区/参数区若进 QScrollArea，关键标签设最小高度防截断（v3.3.0）。
8. **回退开关**：3.10.0 提供「经典布局」选项（设置项 + 环境变量 `SLIME_CLASSIC_LAYOUT=1`），保留至少一个版本。
9. **不删入口**：设置/帮助移到左导航后，保留快捷键与菜单入口一版过渡；用户找不到 = 事故。
10. **性能不退化**：3.10.0 只改 UI，`perf_baseline --check` 必须通过；算法/结果逻辑零改动。

## 五、GUI 自检新增断言（3.10.0 必须全部覆盖）

| 断言 | 说明 |
|---|---|
| 三列宽度 330 / 770 / 372（±8px） | 基准窗口 1600×1000 |
| **结果列表 20 行时地图高度不变** | 本次改版的核心诉求，防回归 |
| 折叠/展开前后按钮全局坐标完全相等 | 防 v3.6.7-3.6.10 那类位移 |
| 展开态地图高度 ≥ 面板高度 − 60 | 防 addStretch 抢占（v3.6.10） |
| 方案下拉项数 = 模式对应数量（密度 4 / 图案 2） | 防模式与方案脱节 |
| 切换方案后 GPU 三个开关状态不变 | 「加速独立」硬约束 |
| 最小窗口 1180×720 无控件重叠/截断 | 布局校验 |
| 125% DPI 下无截断 | 高 DPI 适配 |
| 「结果行数 = 结果条数」「列表行数上限 = kResultDisplayCap」 | 防 v3.6.7 慢一拍/数量不一致 |
| 经典布局开关可切换且不崩溃 | 回退路径可用 |

## 六、发布与回滚

1. **3.10.0 发版前先打 beta 包自用 1 天**（`-Version 3.10.0-beta`），确认启动/折叠/DPI/双屏；
2. 发版必须跑：单元 34、内核 ALL PASS、117/117、`run_all_tests.ps1`、`perf_baseline --check`、GUI 自检（GPU 开/关）、打包 + 安装包冒烟、审计；
3. **回滚路径**：设置里切「经典布局」→ 仍异常则回退上一版 zip（3.9.12），缓存/配置向下兼容；
4. 更新历史按既有规范写（版本、类型、要点、回退方式），并通过历史计数断言。
