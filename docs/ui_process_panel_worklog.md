## 21:05~21:35 问题排查（3.10.5）：「够数就停 / 忽略阈值 / 速度」

排查方式：新探针 `tools/opt_probe45.cpp`（区域/阈值/目标/ignore/stop/smart/gpu 全参数矩阵）+ 代码走查。

1. **数量够就停没生效（多因）**：
   - 根因 A：未勾「由近及远」时光栅扫描从地图边缘开始，无损判停要「扫过起点」后才可能满足 ⇒ 实际扫掉半张图；
     修复：提前停止时自动按距离由近及远（结果仍为最近 N）。
   - 根因 B：并行早停批次 = 线程数×行块（8 线程≈2048 行），小区域一批扫完全部 ⇒ 判停永不触发；
     修复：每批 ≤2 行块（≈512 行）判停一次。
   - 根因 C：GPU 大区域在「智能范围」下不走行带 ⇒ 无法早停；修复：提前停止时按距离行带派发，凑够即停。
   - 实测：2000² 由全程 → 10 ms 早停；4000² 54 → 21 ms；「已找到」=目标数。
2. **忽略阈值**：引擎路径正确（探针 70000²：阈值 0.99 仍 20 条、密度降序；单元测试 36 分块/经典一致）。
   用户感觉「没生效」的主因是**该模式为 CPU 实现、大范围很慢**（70000² ≈ 11.5 s；修复前 11.9 s，
   本版把填充换成整行内核，但选择阶段仍 CPU 瓶颈）。建议缩小范围使用。
3. **速度**：普通 GPU 搜索保持单次全量派发；CPU 性能基线 30% 容差内通过；参考对拍 117/117。

验证：3 轮 GUI 自检 0 FAIL（p5_1/p5_2/p5_3）+ 终验（final_3105）；打包 3.10.5 完成。
