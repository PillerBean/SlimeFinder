## 一、环形语义纠正（本轮核心）

之前把「环形」实现成了**整个圆盘**（0~128），错误。按用户定义修正：

> 环形 = 怪物在玩家周围**可生成**的范围：太近（<24）与太远（>128）都不刷 ⇒ 是**环带**。

| 项目 | 旧 | 新 |
|---|---|---|
| 覆盖区域 | 圆盘 0~128 | **环带 24~128**（`innerRadius=24, radius=128`） |
| 覆盖率分母 | π·128² | **π(128²−24²)** |
| 覆盖区块判定 | 区块与圆相交 | 区块矩形与**环带**相交（精确的最短/最远距离判定） |
| 卷积核（粗扫） | 圆的交叠表 | **外圆交叠 − 内圆交叠**（缓存键含内半径） |

界面实测（截图）：状态栏 →
`环形 24~128 格｜按 y=1 统计：64 个站位，最优 7320 格 / 31 区块 / 覆盖率 14.2%（用时 0.159 秒）`
结果表新增「区块 · 加权」列（如 `31 区块 · 7247`）。

### Y 层口径
统计取「世界倒数第二层」：**洞穴更新（1.18）前 y=1，之后 y=-63**（世界最低层 +1），
在状态栏明确写出，避免"到底按哪层算"的歧义。

## 二、搜索模式解耦（按你的要求）

| 类别 | 选项 | 互不干扰 |
|---|---|---|
| 搜索模式 = **图案** | 方向锁定、绘制图案 | 密度选项（网格/最小密度/智能范围）自动置灰 |
| 搜索模式 = **密度** | 网格大小、最小密度、智能范围 | 图案选项自动置灰 |
| **区域形状** = 正方形 / 环形 | 环形属密度类（支持最小密度、目标数量） | 环形时图案模式被禁用并自动切到密度 |
| **判定算法**（精确/分层/估算/保守） | 只影响速度与准确率 | **两种模式都可用**，不再标"仅密度搜索可用" |

修了一个 Qt 陷阱：四个单选按钮同属一个父控件时会**自动互斥**（切密度把环形取消）。
现在「区域形状」和「搜索模式」各用一个 `QButtonGroup`，彻底隔离。

## 六、已知限制

1. 权重网格按 1:64（4×4 区块）取样，群系边界处权重可能 ±1 格误差（只影响排序）。
2. 环形范围上限 4096×4096 区块（更大的范围会自动加粗扫步长）。
3. 环带内「完全覆盖/部分覆盖」目前只在格子计数上体现（面积按格子精确算），地图高亮是"相交即高亮"。
4. 基岩版无群系权重；结果列表最多显示前 500 条。
