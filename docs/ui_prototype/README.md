# SlimeFinder UI 原型（直角风格 · 三纵列 · 方案 A）

> 用途：**交互原型**，用于确认布局与视觉细节；不含真实搜索功能。
> 直接用浏览器打开 `index.html` 即可（无需服务器、无外部依赖）。

## 快速体验路径

1. 顶部全局设置栏：切 **游戏版本 / 平台（Java·基岩）/ 世界种子**（种子可点 ⟳ 随机）；
   （设置、帮助入口只在**左下导航**，顶部不再重复）
2. 左列「结果要求」：**先选模式，再选方案** —— 模式决定可用的方案数量：
   密度模式 4 种（快速找最近 N 个 / 找全部候选 / 最优 N 个（忽略阈值）/ 大范围粗筛），
   图案模式 2 种（找最近 N 个（提前停止）/ 找全部候选）；选「最优 N 个」会看到阈值与早停被禁用（冲突裁决演示）；
3. 切 **模式** 到「图案搜索」：阈值行隐藏、出现图案编辑器（点格子循环切换三态）与「锁定方向」；
4. 点 **开始搜索**：地图顶部出现进度浮层，右列结果实时追加，过程面板分阶段推进，完成后显示
   「已提前停止（无损）」横幅；再点一次可模拟取消；
5. 左侧导航（56px 方形图标条）：**搜索 / 设置 / 缓存构建 / 更新历史**，可点击切换（仅演示选中态）；
6. 「加速」卡片是**独立开关**：切换方案不会改变它（可自行验证）。

## 这版原型相对现状的改动

| 改动 | 说明 |
|---|---|
| **直角 UI** | 全部控件 `border-radius: 0`；用 1px 边框 + 2px 主色条表达层级与选中，不再用圆角 |
| **左侧导航优化** | 88px 宽竖排 → **56px 方形图标条**：图标 + 9px 标签、左侧 3px 绿色激活条；条目精简为 搜索 / 设置 / 缓存构建 / 更新历史；顶部不再重复设置与帮助 |
| **新增全局设置栏** | 顶部常驻：游戏版本 / 平台（Java·基岩）/ 世界种子（含随机）/ GPU 状态 / 线程 / 设置 / 帮助 |
| **三纵列** | 参数 300 \| 地图自适应 \| 结果+过程 340；地图高度拉满，结果列表不再挤压地图 |
| **结果要求顺序** | 先「模式」再「方案」：模式决定方案数量与可用项；方案行下方给出「N 种方案 · 特点」提示 |
| **地图语义简化** | 去掉看不懂的「候选环」，改为 **搜索范围虚线框 + 结果候选编号**；图例含 4 项 |
| **结果与过程同列** | 结果表（行高 34、密度迷你条、低于阈值橙标）+ 过程面板（阶段条 / 语义横幅 / 日志 / 页签） |
| **过程可视化** | 地图进度浮层、状态栏进度、过程面板三段条、横幅三种语义（运行中/无损/有损） |
| **底部页签取消** | 原「进度/反馈/日志/终端」并入过程面板页签，腾出地图纵向空间 |

## 已知限制（原型，不实现）

- 地图是 CSS 网格 + 随机绿点示意，不可缩放/拖动（按钮为占位）；
- 结果行是模拟数据，随机生成；
- 顶部「设置 / 帮助 / 导出」等按钮只弹提示；
- 切页导航（地图/结果/环形/缓存/设置/帮助）只切换选中态；
- 未实现键盘快捷键（仅显示提示）。

## 下一步（转成真 UI 时）

4. 全局设置栏接入配置（版本/平台/种子），并保留「加速」独立开关不与方案联动。
