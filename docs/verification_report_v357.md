## 二、本轮改动

### 1. 地图加载/移动流畅度
- 把「群系底图 + 史莱姆区块 + 网格」合成为一张 **QPixmap 缓存**（覆盖视口 + 25% 余量，单张 ≤4096²）；
- 平移时**直接位移贴图**（0 重算）；缩放变化才重建；静止 120ms 后再重建一次；
- 史莱姆区块数量统计按「视图中心 + 缩放」缓存，不再每帧重算；
- `SLIME_MAP_PROFILE=1` 可打印底图重建耗时，便于以后排查。

### 2. 环形算法：1/16 精度 + 权重 + 完整指标
- 最终候选始终按 **1 格（1/16 区块）精度**精修；
- Java 版**自动带群系权重**：一次性用 `genArea(1:64)` 预取整个搜索范围的权重网格（4×4 区块一格），
  planner 的 `weightAt` 变成数组索引；
- 每个候选给出：**覆盖面积（格）、覆盖区块数、覆盖率%、加权覆盖、平均权重**；
- 结果列表新增「区块 · 加权」列（正方形模式自动隐藏），排序优先看加权覆盖。

### 3. 环形提速（专门算法）
- 区块级卷积粗扫（16×16 区块 ∩ 半径圆的交叠表）→ 局部 3×3 区块 1 格精修；
- **OpenMP 并行**粗扫（按行分块，每线程本地收集后合并）；
- **卷积核按半径缓存**（同一半径不再重算 289×256 次）；
- **权重网格一次预取** + **BiomeMap 生成器复用**（避免每次搜索 setupGenerator ~0.8 秒）；
- 精修候选数 64 → 32（权重模式下每个都要精确算）。

## 四、已知限制

1. 权重网格按 1:64（4×4 区块）取样：群系边界在区块级别可能有 ±1 格误差（排序用，不影响覆盖面积）。
2. 地图底图缓存单张上限 4096×4096，超大窗口会自动放弃余量（仅在边缘拖动时更早触发重建）。
3. 环形搜索的大范围仍受 4096×4096 区块上限保护；超大范围自动加大粗扫步长。
4. 基岩版无群系权重（按纯面积）；结果列表最多显示前 500 条。
