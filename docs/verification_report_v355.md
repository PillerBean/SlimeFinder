## 二、这次踩的坑（已修，写进教训）

- **启动崩溃 0xC0000005**：重写右栏时把 `infoStats` / `modeWarn` 的创建语句丢了，布局里塞了 `nullptr`。
  修复方式：补回创建（`QLabel` + `setWordWrap`，`modeWarn` 默认隐藏）。
- **同类风险**：`m_w->resultView` 的创建也曾丢失（回滚时又把 `nullptr` 加进布局）。
  现在所有新控件都遵守「**先创建、再进布局**」，并加了静态检查（列出「被使用但从未赋值」的成员）。
- 教训：改 UI 必须一条一条加、每条跑自检；本次按 A 方案执行：先把树恢复到绿色基线（160 条自检零崩溃），
  再分 5 步叠加（①地图三档/坐标轴/悬停 ②最大化 ③环形算法 ④结果列表 ⑤方形地图），每步都绿。

## 四、已知限制

1. 结果列表最多显示前 500 条（「复制结果」仍是全量）。
2. 环形覆盖受 planner 窗口限制：最多 **64×64 区块**，超出会在状态栏提示缩小范围。
3. 折叠状态不写入配置（重启恢复展开）。
4. 基岩版仍无群系数据（地图只画史莱姆区块/网格），权重只在 Java 版生效。
5. 鼠标悬停群系名用 cubiomes 英文名（未做中文本地化）。
