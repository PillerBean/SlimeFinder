## 二、骨架（线框图 → 实际布局）

```
菜单栏 26（原生 QMenuBar：文件/编辑/查看/工具/帮助）
工具栏 32（▶ 开始搜索 / ■ 取消 / 导入缓存 / 清除缓存 / 帮助 ｜ 右侧：当前模式 + 缓存摘要）
进度行 34（阶段 ｜ 进度条 1fr ｜ 唯一百分比 ｜ 阶段尾「② 匹配　③ 排序」）

  ① 搜索页：40% 参数卡片（版本与种子 / 搜索范围 / 模式与匹配 / 匹配方式 / 性能 / 缓存）+ 60% 结果栏（横向列表 + 汇总条 + 复制/导出）

  ④ 更新历史页：左侧版本索引 104（点击跳转）+ 右侧可展开列表（版本 / 日期 / 正式版-测试版 / 明细）
```

实现要点：左导航与标签页**同源**（`showPage(i)` 同步两者选中态与主按钮文案：进「构建范围」→「▶ 开始构建」）；
左导航底部图标条（4 个分类 + 收起）控制停靠面板展开/收起（收起=高度归 0、行由布局 auto 承载）；
导航图标按原型的线性 SVG 风格用 `QPainter` 绘制（20×20 / 1.6px 描边 / 取自调色板前景色，深色自动适配）。

## 三、适配说明（"适当修改适配"部分）

| 原型 | 本次落地 | 原因 |
|---|---|---|
| 左上「交付导航」条 | **不实现** | 原型自带（交互原型/线框图/样式规范/审计结论），不属于应用界面（原型 CSS 亦标注为"本文件独有"） |
| 设置作为独立页 | 设置页=嵌入 `SettingsDialog` 内容（同一套 5 标签与 config 读写） | 不复制一份设置逻辑，避免两处不一致；弹窗入口仍可按需打开 |
| 更新历史手风琴 | `QTreeWidget`（顶层=版本行，子项=明细）+ 左侧版本索引 | 与原型信息结构一致，且复用既有 `UpdateHistory.cpp` 数据源（39 条） |
| 停靠面板抓手拖拽 | 复用竖直 `QSplitter` 分割条（5px）作抓手 | Qt 原生即可拖拽调高，无需自绘 grip |
| 结果列表 | 保留既有 `QTextEdit` 结果视图（等宽、可选中、右键复制） | 结果行为/复制语义（含 `/tp` 反推）已在 v3.3.8.1 定稿，重写列表会带来回归风险 |
| 构建页四段进度条 | 单条进度 + 四项文案（已记录/百分比/速度/已花费）+ 阶段区分 | 与引擎实际阶段（扫描∥判定、归并、落盘）对应，避免"四个假进度条" |

## 五、已知限制

1. 结果列表仍是文本视图（未改为逐行控件列表）：功能与复制语义优先，视觉上按原型的行高/斑马纹/悬停色由 QSS 提供。
2. 「构建范围」页的预算与范围与搜索页**同一份**；预算改动会立即写入 `config.json`（cache.maxSizeMB）。
3. 设置页嵌入的是同一个 `SettingsDialog` 实例（`setWindowFlags(Qt::Widget)`），因此工具栏「设置」按钮不再弹窗，
   而是切到设置页（如需保留弹窗入口，可后续加一个菜单项）。
4. 界面为**结构性重建 + 全量换肤**；原型的像素级间距（如卡片内 58px 标签列）由 Qt 布局按内容决定，未逐像素复刻。
