# v3.5.0 交互手感微调记录（不动主题视觉）

本轮是自发的交互优化（没有改任何配色/排版/图标/字体，只改**事件处理、快捷键、面板行为与尺寸手感**）。

## 一、自己发现的问题（4 条）

| # | 问题 | 影响 | 判定依据 |
|---|---|---|---|
| 1 | **下拉框/滑块会吞滚轮**：鼠标划过「匹配方式」「分层级别」等下拉框时滚动页面，选项会被悄悄改掉（数值框早就有防护，下拉框/滑块没有） | 手滑就改了搜索参数，结果与预期不符，且不易察觉 | 源码：`installWheelFilter()` 只给 `QSpinBox/QDoubleSpinBox` 装了过滤器；全程序有 7 个下拉框 + 1 个滑块没有防护 |
| 2 | **停靠面板图标不能收起**：点击已展开、已选中的图标没有反应，只能去点最下面的「收起」小箭头 | 想关掉底部面板时先要去点另一个按钮，来回两次点击 | 源码：`showDock()` 无条件展开，从不切换 |
| 3 | **页面切换只能靠鼠标**：4 个页面没有键盘入口；搜索跑起来后想取消只能用鼠标点工具栏（打断操作流） | 键盘用户/正在输入时来回抓鼠标 | 源码：只有 `Ctrl+O/S/Q/C/L/0` 与 `F1`，没有页面快捷键；也没有 Esc 处理 |
| 4 | **分隔条拖歪了没法快速复位**：只能靠菜单「重置布局」（`Ctrl+0`，会连带重置窗口尺寸） | 只想把分栏拖回原位却要重置整个布局 | 源码：分隔条没有双击行为 |

## 二、改了什么（4 项，全部是交互层）

1. **滚轮防手滑**：`installWheelFilter()` 顺带给全部 `QComboBox`（7 个）与 `QSlider`（1 个）装过滤器；
   `eventFilter()` 遇到这两类控件的滚轮，一律把事件转交外层滚动区（新增 `forwardWheelToScrollArea()` 公共函数），
   **值只能点开选/拖动改**，滚轮永远只滚页面。
   *（数值框原有「设置开关 + 转发滚动区」逻辑原样保留，只把转发部分抽成同一个函数，行为不变。）*
2. **停靠图标再点一次 = 收起**：`showDock()` 增加「已展开且已选中 → `hideDock()`」判断。
3. **键盘手感**：`Ctrl+1/2/3/4` 直达 搜索 / 缓存构建 / 设置 / 更新历史；
   `Esc` = 取消进行中的搜索/构建（等价于工具栏「取消」，仅在任务进行中生效，空闲时什么也不做）。
4. **分隔条双击复位**：双击中间分隔条 → 恢复默认比例（左栏 400、底部约 180，随窗口自适应），
   状态栏给一句「已恢复默认分栏」提示。

**主题/视觉零改动**：没有动 `ThemeManager`、`styleSheet`、调色板、图标绘制、字号、间距、布局结构。
