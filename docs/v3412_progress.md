## 二、自检新增（GUI 第 27 组）

- 单位外置：整个设置页 + 构建页扫描 `suffix` 断言为 0，框外单位标签 ≥6（实测 13）。
- 构建页结构：三个按钮对象必须为空、实时预估卡片必须存在且随预算变化（改预算 → 卡片同步）。
- 构建模式免检查：构造「严格模式 + 未画图案」的状态后 `startSearch` 必须真的开跑（不回弹「参数错误」）。
- 灰字删除：把检查范围收敛到**设置页**（v3.4.12 教训：按整窗查会被更新历史正文里的同一句话误报）。
- 候选框截图：新增 `cmd-tab-popup` / `cmd-tab-popup-all` 两张交付截图。

## 三、自检抓出的真实缺陷（用户没提，但确实是错的）

1. **更新历史条目数断言仍是旧值**（45 / 「1.0.0 → 3.4.9」）⇒ 已改 46 / 「1.0.0 → 3.4.12」，避免「加了条目却断言旧数」的假绿。
2. **编译告警 6 处**：自检 `fprintf` 的 `%d` 配 `qsizetype`（C4477，5 处）+ 更新历史表头正则里 `\.` 被当成非法转义（C4129）⇒ 前者统一 `%lld` + `static_cast<long long>`，后者写成 `\\.`。现在**编译零警告**（此前只有 `error C` 检查，告警会积累）。
3. **自检会留下自己的缓存文件**（曾达 16.8 MB），导致下次启动变慢/疑似卡住 ⇒ 自检收尾删除自建缓存文件，并在日志里写明大小。
4. **临时诊断面包屑**（`[启动] …` 六行）在定位完成后移除，交付日志保持干净。
