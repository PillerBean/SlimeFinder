# v3.5.18 验证报告（测试版）

- 版本：v3.5.18（测试版；正式版仍只有 2.8.4 / 3.1.1 / 3.3.0 / 3.5.0）
- 主题：**搜索模式两级化（图案 | 密度）· 图案编辑器内嵌 · 高级调试参数 · 文案单一入口**

## 一、这一轮改了什么

| # | 要求 | 实现 |
|---|---|---|
| 1 | 搜索模式只有两种：图案 / 密度；下方只显示可调选项，不能置灰 | 面板重排：一级 `图案 / 密度`；二级按模式整块显示/隐藏 —— 图案模式只显示图案选项（含编辑器），密度模式只显示形状与形状专属参数（正方形：网格大小；环形：扫描模式 + 最小密度）。**不再用 setEnabled 置灰** |
| 2 | 图案绘制界面整合进去，不再弹窗 | 新增 `PatternEditorPanel`（行列 / 画布 / 应用行列 / 全部忽略），直接嵌在「图案」下；画布变化即时写回图案状态 |
| 3 | 智能范围偶尔勾不上 | 改为「只显示/隐藏」：环形时整行隐藏，其它时候可见且始终可勾（不再依赖 enable 状态） |
| 4 | 文案优化 + 多语言扩展空间 | 新增 `src/gui/UiStrings.h`：枚举 Key + 中英双语表 + `ui::text()` 单一入口；设置-高级的 9 条文案已迁移作为示范，旧文案可按页面逐步迁移 |
| 5 | 设置-高级新增精细化调参 | 高级页新增「高级调试参数」：环形内半径 / 外半径 / 粗扫步长 / 严格统计行带数（默认 24 / 128 / 4 / 4），写入 config.json（`settings.ringInner` 等）并即时生效 |
| 6 | 继续提速 / 新算法 | 见 [加速方案](speed_plan.md)：AVX2 手写粗扫内核（预计 1.5~2.5×）、分层筛（预计 2×）、位集+位平面（预计 2~4×），含成本模型与实施顺序；本轮先落地结构改造，未改动搜索口径 |

## 二、界面结构（现在的样子）

```
搜索模式
  (•) 图案搜索   ( ) 密度搜索
  ┌ 图案模式 ─────────────────────────────
  │  [x] 方向锁定（不旋转/翻转）
  │  图案：5×5，3 个有效格
  │  [内嵌图案编辑器：画布 + 行/列 + 应用行列 + 全部忽略]
  └
  ┌ 密度模式 ─────────────────────────────
  │  区域形状: (•) 正方形   ( ) 环形
  │  ── 正方形：网格大小
  │  ── 环形：环形扫描（快速/精确）+ 最小密度
  └
  目标数量 / [ ] 找够目标数量就停止 / [ ] 由近及远
```

## 四、行为变化（需要知道）

- 「环形时不能切回图案模式」这条旧约束**去掉了**：现在图案/密度是一级选择，形状只属于密度；
  切到图案时密度整块隐藏，切回密度时形状选择保留。
- 旧的「绘制图案」弹窗仍可从工具菜单打开（兼容），但搜索页里用的是内嵌编辑器；两者编辑的是同一份图案状态。
- 设置-高级的 4 个数字直接改变搜索口径（半径/步长/行带数），默认值与旧行为一致。
