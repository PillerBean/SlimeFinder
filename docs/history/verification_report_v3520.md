# v3.5.20 验证报告（测试版）

- 版本：v3.5.20（测试版；正式版仍只有 2.8.4 / 3.1.1 / 3.3.0 / 3.5.0）
- 主题：**两种全屏 · 语言记忆修复（重启生效）· 大范围环形再提速**

## 一、这一轮改了什么

| # | 要求 | 实现 |
|---|---|---|
| 1 | 两种全屏：无窗口全屏 / 有窗口全屏 | 设置-通用新增「全屏方式」：**无边框全屏**（`showFullScreen`，无标题栏铺满）/ **窗口最大化（有边框）**（`showMaximized`）。默认无边框；**F11** 随时切换（写回 config.json，重启保持） |
| 2 | 切换语言提示立即重启 | 语言不再即时套用：应用设置时只存盘并提示「界面语言已保存，重启程序后生效」；启动时在**建界面之前**读取语言（文案在建控件时就取） |
| 3 | bug：语言设置不被记忆 | 根因：只写了 config 的 `settings.language`，**从来没读回来**。已在 `loadAppSettings` 补读（`cfgString`），并补上 `settings.fullscreenMode` |
| 4 | 继续优化（速度） | 快速模式增加「粗扫候选点数预算」（约 40 万）：大范围自动加步长，1 格核精修 + 3×3 抛光照旧。**1000×1000 区块 38→28 ms、2000×2000 区块 70→46 ms**；400×400 及以下完全不变（候选清单与 v3.5.14 参考一致） |

## 二、速度对比（`--bench-ring`，R=128 内 24，种子 12345）

| 范围 | v3.5.19 | v3.5.20 | 提升 |
|---|---|---|---|
| 400×400 区块 | 18.0 ms | 18.6 ms | 持平（步长仍为 1，最优解相同 -1609,-831） |
| 1000×1000 区块 | 38~41 ms | **28.0 ms** | ≈1.4× |
| 2000×2000 区块 | 70~108 ms | **46.0 ms** | ≈1.5~2.3× |
| 20000×20000 区块 | ~98 ms | ~98 ms | 抽样模式，不变 |

质量核对：16 / 44 / 100 / 200 / 400 区块的候选清单与既有参考逐行对比，差异仍是历史那 12 行（来自抛光数量与网格档位的既有设定），**本轮没有新增差异**。

## 四、下一步（速度）

- 粗扫仍是大头（400×400 约 4~6 ms、2000×2000 约 34 ms）。下一个确定收益是 **AVX2 专用编译单元**：
  MSVC 没有函数级 target 属性，必须把散射内层放进独立 TU 用 `/arch:AVX2` 编译，并在运行时用 CPUID 分派（无 AVX2 时走标量）。
  预计 1.5~2.5×；再叠加分层筛（1/4 分辨率粗核预筛）预计整体 3~5×。详见 [speed_plan.md](speed_plan.md)。
