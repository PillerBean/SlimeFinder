# v3.5.26 验证报告（测试版）

- 版本：v3.5.26（测试版）
- 主题：**进度条（显示/红色提醒）· 地图缩放到最小仍上色 · 密度判定 · 设置立即生效 · 命令补全 · 群系版本选择**

## 一、逐条对应

| # | 反馈 | 处理 |
|---|---|---|
| 1 | 搜索时进度条不增长 | 所有搜索开始先进入**忙碌滚动**模式（`setRange(0,0)`），第一次拿到真实进度再切回百分比；环形搜索同样有进度（计算中滚动，完成 100%） |
| 2 | 缩到最小时地图不再上色 | 采样超限时不再清空群系图，**保留上一张**（放大后自动重采样） |
| 3 | 精确搜索过度卡顿 | 环形后台线程降到 `THREAD_PRIORITY_BELOW_NORMAL`，不再把 UI 线程饿死 |
| 4 | 最小密度与结果密度接近时误判为合格 | 改成按**界面显示值（3 位小数）**比较，不再出现「表格显示 30.0% 但实际 29.96%」的矛盾 |
| 5 | 语言切换被错误回退 | 恢复**即时切换**：已迁移文案立刻生效，其余提示重启后完全生效（不再假装必须重启） |
| 6 | 选项切换仍然无法立即生效 | 去掉「控件还停在旧默认值才覆盖」的启发式 —— 设置页改了就直接套用到当前搜索页 |
| 7 | 保证任何搜索都有进度条 | 同 #1（引擎搜索 / 环形 / 缓存构建三条路径都有） |
| 8 | TAB 补全栏占一整行 | 候选框宽度按最长候选收窄（最多不超过输入行宽） |
| 9 | 输入时自动展示候选词 | `QLineEdit::textEdited` → 自动弹出候选（Minecraft 命令栏风格），不用按 Tab；Tab 仍可循环选择 |
| 10 | 0 结果时进度条变红 | 完成时结果为空 → 进度条 chunk 变红（`#d9534f`），有结果时恢复 |
| 11 | **新增**：除平台外还要历史版本选择 | 搜索页「游戏设置」新增**群系版本**下拉（27 个版本，1.0 ~ 1.21.3 + Beta），驱动地图上色与环形群系统计，并写入 `config.json`（`settings.mapVersion`）；基岩版选到 1.18 之前会自动回落到最新（1.18+ 才与 Java 同种子一致） |
