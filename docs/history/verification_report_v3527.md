# v3.5.27 验证报告（测试版）

- 版本：v3.5.27（测试版）
- 主题：**切版本后缩到最小不上色 · 设置生效时机提示 · 英文覆盖扩大**

## 一、逐条对应

| # | 反馈 | 根因 / 处理 |
|---|---|---|
| 1 | 反复切平台/版本后再缩到最小，地图不加载颜色 | 切版本会清空群系缓存；缩到最小时需要采的格数（含 25% 余量）超过上限 → 直接放弃。现在**先去余量、只采视口重试一次**（最小缩放时视口本身通常在预算内），仍超限才保留上一张。日志新增一次性提示「视野过大：群系保持上一张」 |
| 2 | 部分设置要完全重启才生效却没提醒 | 设置页标注：「窗口大小记忆（下次启动）」「日志文件目录（下次启动）」「启动时检测（下次启动）」「CPU/内存上限（下次搜索）」「界面语言（重启后生效）」；对话框底部新增统一提示行：「标注『下次启动 / 重启后生效』的设置不会立即生效；其余设置点『应用』后马上生效」 |
| 3 | 英文覆盖面不够 | 新增**运行时翻译表**（中文原文 → 英文）+ `MainWindow::applyLanguage()`：递归改写所有 QLabel / 按钮 / 分组框 / 下拉项 / 菜单动作的文本（约 70 条常用文案），首轮把中文原文记进 `zhText` 动态属性，来回切换不丢原文。切换语言即时生效，重启后整体英文 |

## 二、英文切换的验证方式

- 把 `config.json` 的 `settings.language` 设为 `en` 后启动：界面显示 `Density` / `Bedrock` 等英文；
- 自检在英文环境下**依然全过**（自检开始时强制切中文跑断言，且自检期间忽略语言变化，避免断言依赖界面语言）；
- 切回中文后界面恢复，`zhText` 属性保证无残留。
