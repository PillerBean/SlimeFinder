## 一、本轮改动

| # | 用户反馈 | 处理 |
|---|---|---|
| 1 | 「环形搜索是密度搜索中的子选项，与正方形区域搜索同级」 | 在**搜索模式**组顶部新增「区域形状」：**正方形** / **环形覆盖**；把原来混在「搜索算法」里的环形单选**删掉**（自检断言 `algRingRadio == nullptr` 钉死层级） |
| 2 | 「选择环形搜索后让无关选项变灰」 | 选环形时置灰：严格图案/密度搜索、方向锁定、绘制图案、网格大小、最小密度、达到数量、目标数量、智能范围、**整个匹配方式组（5 个算法 + 参数）**；状态栏说明「半径固定 128 格；与密度/图案相关的选项已置灰」 |
| 3 | 「环形 = 生物刷新区域，大小固定；之前疑似把搜索范围当环形大小」 | 语义明确：`radius = 128` 是**固定刷新半径**，搜索范围只决定「允许在哪儿站」。移除旧的 64×64 区块限制 |
| 4 | 「需要查找远处的最佳环形挂机点」 | 新算法：**区块级卷积粗扫 + 局部 1 格精修**。60×60 区块下与精确解**完全一致**（(-346,394) 覆盖 8521 格）；600×600 区块（9600×9600 方块）**0.18 秒**；400×400 区块在界面里 0.15 秒 |
| 5 | 「悬停显示群系止步于最大精度，再放大对不上」 | 悬停改为按**当前显示精度**查询（1:1 时按 1:1 查），缓存键带精度 |
| 6 | 「精度自适应只保留最高的两种」 | 自适应只剩 **1:1（≥4px/格）/ 1:4（更远）**，1:16 与 1:64 移除 |

## 四、已知限制

1. 超大范围时粗扫按区块步长（600×600 内步长=1；更大时自动加步长），最终点仍在粗点的 ±1 区块内精修到 1 格。
2. 环形模式不支持群系权重（大范围下按区块中心采样权重，仅用于排序参考）。
3. 基岩版仍无群系数据；地图只画史莱姆区块/网格。
4. 结果列表最多显示前 500 条。
