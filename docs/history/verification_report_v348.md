## 五、已知限制与说明

1. **严格模式未锁定方向（四向旋转）+ 达到即停**：现在也能提前停止（评估窗口 640000 → 82000），
   仍保证「全局最近 N」。若要更激进的停止，可勾选「方向锁定」（单变体，停得更早：8 万 → 更少）。
2. 进度条绿色在**禁用态**仍为灰色（避免把"不可用"画成"进行中"）。
3. 「恢复所有设置」只重置设置项，不删除缓存文件；搜索范围等"本次任务"参数不在设置范围内（按钮旁有小字说明）。
4. 更新历史的写作要求（面向普通用户、不写开发过程）写在 `src/gui/UpdateHistory.cpp` 文件头，后续版本按此维护。
5. 本报告写在打包之后（需要先产出 zip 才能记录哈希），因此 zip 内的 docs 快照不含本文件；
   仓库 `docs/` 与 `dist/SlimeFinder/docs/` 两侧内容一致（审计的 docs 副本比对为 identical）。
