# v3.5.17 验证报告（测试版）

- 版本：v3.5.17（测试版；正式版仍只有 2.8.4 / 3.1.1 / 3.3.0 / 3.5.0）
- 主题：**地图精度两档 · 环形两种扫描模式 · 超大范围静默无结果修复 · 无结果不再跳地图**
- 交付物：`dist/SlimeFinder-3.5.17-win64.zip`、`dist/SlimeFinder-3.5.17-Setup.exe`

## 一、这一轮改了什么

| # | 反馈 | 根因 | 处理 |
|---|---|---|---|
| 1 | 地图精度还有三种，只要最高两种 | v3.5.15 为压采样量加了 1:16 档 | `biomeScaleForScale()` 只返回 **1 或 4**；极端缩小也是 1:4（采样量由图层格数上限兜底，超限不画群系而不是降精度） |
| 2 | 环形扫描范围还是太小 | ① `plan()` 里范围面积用 **int 相乘**：320000×320000 直接溢出成负数 ⇒ 超大范围被当成「无效范围」**静默返回 0 个结果**；② 面积极大时占用图铺满会爆内存 | ① 改 int64；② 超大范围（>2 亿区块）新增**等距抽样粗扫**（每样本直接算 17×17 区块窗口核分，不铺占用图，内存/耗时都有界），随后仍走 1 格核精修 + 抛光 |
| 3 | 要两种环形搜索模式 | — | 新增「环形扫描」下拉：**快速（粗扫+精修）** / **精确（逐区块）**；`AfkPlanOptions::scanStride`（0=自动，1=逐区块） |
| 4 | 部分情况搜出结果但列表不显示 | 计划结果与列表/状态的显示条件不一致（近似筛选 vs 严格复核） | 计划与列表统一用严格复核后的候选；被最小密度筛空时给出明确状态而不是「没结果」 |
| 5 | 无结果时地图「虚空跳转」 | 无候选时仍然 `fitToContent()`，把视图拉回原点 | 只在有候选时 fitToContent；空结果保持当前视图 |
| 6 | 大范围「说没结果」 | 同 #2 的溢出 | 同 #2；另加抽样模式日志「超大范围抽样：… 步长 …」 |

## 二、环形范围现在能到多大

| 范围 | 模式 | 耗时 |
|---|---|---|
| 400×400 区块 | 快速 | 17~20 ms |
| 2000×2000 区块 | 快速 | 70~108 ms |
| **20000×20000 区块（4 亿）** | 快速（抽样 625×625） | **≈98 ms**（网格 6 ms + plan 88 ms） |
| 任意更大 | 快速 | 抽样数固定 ~40 万 ⇒ 秒级有界 |
| 任意 | 精确（逐区块） | 与面积成正比，超大范围会很慢（UI 有提示） |

## 三、环形 vs 正方形（同片区、同种子、同样 8 个结果）

| 范围 | 正方形（密度 g=5） | 环形（快速） | 倍数 |
|---|---|---|---|
| 400×400 区块 | 4.0 ms | 18.9 ms | 4.7× |
| 1000×1000 区块 | 8.6 ms | 38.7 ms | 4.5× |
