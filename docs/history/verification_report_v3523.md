# v3.5.23 验证报告（测试版）— 把 v3.5.22 遗留项做完

- 版本：v3.5.23（测试版）
- 主题：**设置项立即生效 · 地图拖动流畅度**

## 一、这一轮补完的两项

| # | 遗留项 | 原因 | 处理 |
|---|---|---|---|
| 1 | 大部分设置项无法立即生效 | 搜索默认值（线程数 / 目标数量 / 判定算法 / 找够即停 / GPU 加速 / 快速预设）**只在启动时套用一次**（`MainWindow` 构造里那段），之后改设置什么都不会发生 | `applyAppSettings()` 里新增「立即套用」块：改完马上作用于当前搜索页；为避免抹掉用户手改值，**只覆盖仍等于旧默认值的控件**；生效项会写进反馈栏（「以下设置已立即生效：线程数、目标数量…」） |
| 2 | 地图拖动不够流畅 | 拖动每一帧都会触发重采样（`scheduleResample()`），底图重建和拖动互相抢时间 | 拖动中**不重采样、不重建底图**，只平移已有缓存图；`mouseReleaseEvent` 里补一次高质量重建 |

顺带确认：滚轮开关（`wheelAdjust`）、主题、提示音、日志面板参数、缓存目录、崩溃转储、调试模式、更新提醒天数、全屏方式本来就是「即时」语义（事件读取当前设置 / 直接调用），这轮没有改动。
