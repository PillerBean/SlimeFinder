## 一、本轮改动

| # | 要求 | 做法 |
|---|---|---|
| 1 | 地图从导航栏移除，移植进「搜索」页 | 删除第 5 个导航页（导航/页面回到 4 项）；搜索页右侧改为竖直分割：**上=地图面板，下=结果栏**；地图面板标题可折叠（Ctrl+M 或结果区「地图」按钮），折叠后结果栏占满 |
| 2 | 注意三者交互与视觉干扰 | 参数栏（左）/ 地图（右上）/ 结果（右下）各司其职：**参数不再重复一份**（撤销 v3.5.3 地图页的参数面板）；地图标题行只放 4 个轻量按钮（放大/缩小/适应/算挂机点）+ 折叠箭头；结果区仍是原来的文本框，不额外加表格 |
| 3 | 点击结果即可快速定位地图 | 结果视图装事件过滤器：左键按下-抬起位移 ≤4px（拖动选字不触发）时取该行文本，正则解析 `chunkX(a~b) chunkZ(c~d)`，取区块中心 → 地图 `setView` 到该区块中心并**立即重采底图**（不闪白），状态栏提示「地图已定位到区块 (x, z)」 |
| 4 | 地图与信息填写栏同步 | 版本/种子/范围变动 → 250ms 去抖后 `updateMapFromForm()`：刷新 layer、按 Java/基岩切换群系源、以搜索范围中心重设视图并 `refreshNow()`；搜索结果落地也自动刷新 |
| 5 | 帧率/精度/醒目度（上一轮成果保留） | 去抖 + 25% 余量缓存 + 自适应精度（1:1/1:4/1:16/1:64）+ 史莱姆区块加浓描边 |

## 四、已知限制

1. 地图面板宽度/高度可拖（QSplitter），折叠状态不持久化到配置。
2. 点击结果是「单行定位」，不支持框选多条批量定位。
3. 基岩版仍无群系数据（只画史莱姆区块/网格）。
4. 远距离定位会立即重采一次底图（约 3~25 ms），大分辨率下偶见一次轻微停顿。
