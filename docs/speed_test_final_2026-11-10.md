# SlimeFinder 最终速度测试（2026-11-10）

> 版本：v3.10.12.10（Setup-only 发布前的本地构建）
> 硬件：Ryzen 5 5600（6C/12T，全核约 4.1~4.4 GHz）+ RX 6750 GRE 10GB；Windows 11
> 本轮为真实使用场景压测（全图、取消、早停、环形），**不做单元/自检**。

## 6. 与社区归一化数据对比（换算后）

社区归一化口径（见 `docs/community_benchmark_reference.md`）：

- **CPU ≈58.9 亿区块/s**（i9-13900K 归一化到本机）
- **GPU ≈886~1146 亿区块/s**（4060L/3060L 按 FP32 归一化）

### 6.1 CPU

| 本机项目 | 本机速率 | 占社区归一化 CPU |
|---|---|---|
| 纯扫描内核（12T） | 56.1 亿/s | **95.2%** |
| 全图密度产品路径（外推） | 30.8 亿/s | **52.3%** |
| 环形图案（100k²） | 39.4 亿/s | **66.9%** |

### 6.2 GPU

| 本机项目 | 本机速率 | 占社区归一化 GPU |
|---|---|---|
| **全图密度产品路径** | **717 亿/s** | **62.6%~80.9%** |
| 70k² 密度 | 324 亿/s | 28.3%~36.6% |
| 100k² 密度 | 332 亿/s | 29.0%~37.5% |
| 环形图案 100k² | 813 亿/s | **71.0%~91.8%** |
| 环形图案 20k² | 388 亿/s | 33.9%~43.8% |
| 密度 8k² | 143 亿/s | 12.5%~16.1% |

### 6.3 结论

1. **CPU 纯扫描**已达到社区 CPU 工具约 95%（每线程效率非常接近）；
2. **CPU 全图产品路径**只有社区归一化的约 52%，差距来自分块/密度匹配开销（纯扫描不是瓶颈）；
3. **GPU 全图密度**达到社区归一化的 **63%~81%**，比此前文档中的 24%~38% 提升明显；
4. **GPU 环形图案**达到社区归一化的 **71%~92%**（100k² 档）；
5. **GPU 中等范围**（70k~100k²）只有 28%~38%，与全图差异明显：分块规模、命中回写、调度开销在不同几何下差异较大，是下一步可继续挖的点；
6. 环形搜索的「快速全图」是抽样近似（约 0.1 s），与社区“逐环心穷举”不是同一口径，不能直接换算。
