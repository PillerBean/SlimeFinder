# v3.5.28 验证报告（测试版）

- 版本：v3.5.28（测试版）
- 主题：**地图条纹/崩溃修复 · 未填种子不渲染 · 去倒三角 · 状态栏改版 · 工具栏搜索状态面板 · 英文再扩**

## 一、逐条对应

| # | 反馈 | 根因 / 处理 |
|---|---|---|
| 1 | 地图出现条纹随后崩溃 | v3.5.27 加了「超限时只采视口」的降级，但生成像素循环与缓存元数据仍用旧的 `needW/needX0` → **图像实际尺寸与写入步长不一致**（越界写）。已统一改用实际生成尺寸 `nw/nh/nx0/nz0` |
| 2 | 基岩版仍能错误渲染地图 | 空种子守卫改为**两个平台都生效**（基岩版史莱姆区块同样依赖种子）；基岩版群系版本已按所选版本、低于 1.18 回落最新 |
| 3 | 未填种子仍显示「种子 0」的地图 | 未填/非法种子时不再渲染，地图中央显示「请先在上方填写世界种子，再显示地图」，状态栏同步提示 |
| 4 | 英文替换不够大 | 翻译表继续扩：标签页名（进度/反馈/日志/命令）、结果表头、更多按钮/菜单/设置项；`applyLanguage()` 现在也处理 **QTabWidget 页签** 与 **QTableWidget 表头** |
| 5 | 移除设置「预留位置」分组 | 通用页里「预留位置（暂不可用）」整组删除 |
| 6 | 移除输入/选择框的灰色倒三角 | QSS 中 `QComboBox::drop-down` 宽度归零、`down-arrow` 图片置空（浅色 + 深色两套都改） |
| 7 | 底部栏移除右侧信息、左侧放介绍/提醒 | 状态栏右侧的统计/用时/剩余/联系我们全部移除；左侧常驻提醒「先填种子、滚轮默认不吃、F11 切换全屏」 |
| 8 | 红框区域显示搜索状态 | 工具栏新增**搜索状态面板**：`阶段：搜索中/匹配中` ｜ `结果 N` ｜ `已用时 x.x s` ｜ `剩余 m:ss`（由进度回调与 200ms 定时器驱动） |
