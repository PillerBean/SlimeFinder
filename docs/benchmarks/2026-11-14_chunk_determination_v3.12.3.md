# SlimeFinder v3.12.3 区块判定速度

测试日期：2026-11-14  
测试对象：v3.12.3 源码构建的 `slime_chunk_bench`  
测试内容：**只测区块判定**，不测密度/图案匹配。

## 测试环境

```text
CPU：AMD Ryzen 5 5600 6C/12T
GPU：AMD Radeon RX 6750 GRE 10GB（gfx1031，18 CU）
线程：12
```

## 方法

- CPU：`SlimeEngine::fillSlimeRowJava` / `fillSlimeRowBedrock`，按行并行判定，12 线程；
- GPU：`GpuScan::scanRectWords`，包含 GPU 内核计算和结果回读；
- 每个尺寸预热后重复测量，取稳定值；
- 两次 GPU 结果与 CPU 逐块对比，Java/Bedrock 均通过；
- 不计入搜索范围、结果筛选、密度窗口、图案匹配。

## 结果

| 平台 | 后端 | 尺寸 | 区块数 | 耗时 | 判定速度 |
|---|---|---|---:|---:|---:|
| Java | CPU | 4096×4096 | 16,777,216 | 6.19 ms | **27.09 亿/s** |
| Java | CPU | 8192×4096 | 33,554,432 | 12.02 ms | **27.92 亿/s** |
| Java | GPU | 4096×4096 | 16,777,216 | 0.57 ms | **294.96 亿/s** |
| Java | GPU | 8192×4096 | 33,554,432 | 0.93 ms | **361.97 亿/s** |
| Bedrock | CPU | 4096×4096 | 16,777,216 | 47.91 ms | **3.50 亿/s** |
| Bedrock | CPU | 8192×4096 | 33,554,432 | 95.82 ms | **3.50 亿/s** |
| Bedrock | GPU | 4096×4096 | 16,777,216 | 8.59 ms | **19.53 亿/s** |
| Bedrock | GPU | 8192×4096 | 33,554,432 | 16.65 ms | **20.16 亿/s** |

## 对比

以 33,554,432 区块为例：

```text
Java    CPU 27.92 亿/s  →  GPU 361.97 亿/s   约 13.0 倍
Bedrock CPU  3.50 亿/s  →  GPU  20.16 亿/s   约 5.8 倍
```

小尺寸下 GPU 固定启动开销占比更高：

```text
Java   4.19M：CPU 31.06 亿/s，GPU 120.77 亿/s
Bedrock 4.19M：CPU  3.45 亿/s，GPU  16.69 亿/s
```

## 说明

- Java 判定路径明显快于 Bedrock；Bedrock 每个区块需要初始化 MT19937 状态，CPU 单块路径成本更高；
- GPU 数据包含结果回读，因此是端到端判定吞吐，不是纯内核时间；
- CPU 使用 12 线程，结果会受 CPU 频率、后台负载影响；
- 以上均为原始区块判定速度，不是搜索匹配速度。
