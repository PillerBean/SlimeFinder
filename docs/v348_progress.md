## 二、由自检发现并修掉的其它缺陷

1. 设置页所有改动都进不了 `m_settings`（除主题）→ ②⑦ 之外的"设置不生效"总根因。
2. `setInputsEnabled()` 抹掉构建模式禁用 → ③ 的第二个根因。
3. `wholeMapOptions()` 漏算法/分层/采样参数 → 整图估算与实际算法不符。
4. 自检会污染 `config.json` → 下一次运行的"默认值"断言误报（已改为存档/恢复）。
5. `docs/build_instructions.md` 与包内副本不一致（打包后重同步）。

## 六、遗留与说明

1. 严格模式未锁方向时也能提前停止（640000 → 82000 窗口），仍保证全局最近 N；勾选「方向锁定」可停得更早。
2. 进度条禁用态仍为灰色（避免把"不可用"误画成"进行中"）。
3. 「恢复所有设置」不删除缓存文件，也不改搜索范围等本次任务参数（按钮旁有小字说明）。
4. 更新历史的写作要求已写入源码文件头，后续版本按此维护。
