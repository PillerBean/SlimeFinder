> 已选定方案 A：**参数 | 地图 | 结果+过程** 三纵列，地图常驻高度拉满，结果列表独立成列。

## 二、左列：参数 / 结果要求

卡片堆叠，间距 8，页面内边距 12；窄于此宽度时出现纵向滚动条。

| 区块 | 内容 | 细节 |
|---|---|---|
| 顺序 | **先「模式」再「方案」**：模式决定方案数量（密度 4 种 / 图案 2 种），方案行下显示「N 种方案 · 特点」 |
| 方案行 | 「结果要求」标题 + 右侧「方案：快捷」徽章 | 方案下拉：宽 100%，高 30，右侧 `v` 指示 |
| 已修改提示 | 「已修改：找够就停」橙色徽章 | 仅当用户改动偏离预设时出现，点击可「恢复方案」 |
| 模式 | 密度搜索 / 图案搜索 分段控件 | 选中：绿色浅底 + 绿字；未选中：透明 + 次色字 |
| 阈值行 | 「最小密度」标签 72px + 输入框 60px + 「忽略阈值取最优」复选框 | 忽略/图案模式时整行隐藏或置灰（按方案冲突表） |
| 目标数量 | 标签 + 数字输入（宽 46） | 范围 1~999，步进 1 |
| 停止选项 | ☑找够就停 ☑智能范围 | 复选框 13px，间距 8，整行高 34 |
| 加速（独立卡片） | GPU 加速 / GPU 图案流式 / GPU 占用率上限 | 卡片带浅边框；标题「加速（独立开关，不影响结果）」11px 次色；**不随方案变化**；卡片底部注明「仅图案模式生效 / AMD 已验证 / 切换方案不会改变这些开关」 |
| 高级 | 折叠标题「高级 >」+ 算法/分层/采样/图案 | 折叠时只显示标题行（30px） |
| 主按钮 | 「开始搜索」主色 120×34 / 运行中变「停止搜索」（白底红字） | 右侧显示快捷键 `Ctrl+Enter` / `Alt+S` |

m_hSplit->setSizes(QList<int>() << 330 << 770 << 372);

## 十、与现状代码的差异清单

2. 底部页签面板合并进右列「过程」，`m_vSplit` 与之相关的尺寸/折叠逻辑调整；
3. 结果表行高 24→34，列宽调整，密度列改成「数值 + 迷你条」；

## 十一、验收标准（GUI 自检新增断言）

1. 三列宽度在基准窗口下为 330/770/372（±8），且拖动分隔条后比例保持；
2. 结果列表 20 行时地图高度不变化（核心诉求）；
3. 运行中地图出现进度浮层、结果表实时追加、过程阶段条变橙；
4. 完成态横幅文案与 `stoppedEarly/cacheFirstStopped` 标志一致；
5. 窗口缩到最小 1180×720 时无控件重叠/截断；
6. 双击结果行 → 地图定位并高亮该候选（现有功能保留）。
