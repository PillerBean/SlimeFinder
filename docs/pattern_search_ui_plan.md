# 图案搜索（严格模式）UI 规划 v2（简化）

> 用户拍板：**取消图案方案预设、取消「匹配要求」（完全匹配 / 接近匹配）开关**。
> 理由：图案搜索没有太多结果筛选要求，用户真正关心的只有两件事 —— **像不像**、**远不远**。

---

## 一、简化后的结论

图案搜索的「结果要求」其实只有三个要素：

| 要素 | 由什么决定 | 说明 |
|---|---|---|
| **像不像** | **图案编辑器本身**（格子三态：必须史莱姆 / 必须非史莱姆 / 不关心）+ 方向 | 图案就是筛选条件，不需要额外的"匹配要求"开关；结果是 100% 符合图案的窗口 |
| **远不远** | 起点 + 搜索范围 | 结果按距起点距离升序排列，结果列表显示距离 |
| **要几个 / 要不要提前停** | 目标数量、找够就停、智能范围 | 与密度模式一致，共用 |

因此图案模式**不引入方案（预设）下拉、不引入匹配质量开关**，只保留编辑器、方向、目标与停止选项。

## 二、图案模式的面板形态

```
模式：○ 密度搜索   ● 图案搜索
┌ 图案搜索 ─────────────────────────┐
│ 图案： [尺寸 行×列]  [编辑器网格]     │
│ 方向：□ 锁定方向（不旋转）            │
│ 目标数量：[10]   ☑ 找够就停 ☑ 智能范围 │
│ [高级 ▾]  搜索范围 / 起点 / 排序视图    │
│ ── 结果区 ──                        │
│ 距离列 + 坐标 + （若允许旋转）旋转角度   │
└─────────────────────────────────────┘
```

要点：
* 切到图案模式时：**隐藏方案下拉**（预设只服务密度模式），也隐藏密度阈值行；
* 方向：保留现有「方向锁定（不旋转/翻转）」复选框（现状默认勾选、即锁定），文案改为更直白的
  「锁定方向（不旋转）」+ tooltip「取消勾选后图案会按 4 个方向旋转匹配」；
* **结果强调「远不远」**：结果列表固定显示「距起点距离」，并作为排序主键（距离升序）；
* 「像不像」由图案定义，结果天然都是完全匹配，无需匹配度列；若允许旋转，额外显示「旋转 90°/180°/270°」。

## 三、与密度侧新设置的对照关系

| 密度侧 | 图案侧 |
|---|---|
| 方案（预设）下拉 4 个 | **无**（模式简单，不需要预设） |
| 最小密度阈值 / 忽略阈值取最优 | **无对应**（图案本身即条件） |
| 找够就停 / 智能范围 | **相同**（共用开关） |
| 目标数量 | **相同** |
| 结果按密度排序 | 结果按**距离**排序 |
| 结果标密度 | 结果标**距离**（+旋转角度） |

## 四、冲突与误解处理（简化版）

| 情形 | 处理 |
|---|---|
| 图案全为「不关心」格 | 提示「请至少设置一个约束格」，禁止搜索 |
| 图案大于搜索范围 | 提示「图案大于搜索范围」，不启动 |
| 未勾选「锁定方向」时同一窗口多旋转都匹配 | 去重键 = 窗口坐标，保留一个（现有逻辑），结果显示旋转角度 |
| 勾选「锁定方向」 | 只匹配绘制方向，结果不显示旋转 |
| 密度阈值控件 | 图案模式下整行隐藏（不是置灰，减少干扰） |
| 算法选择（分层/估算） | 图案模式隐藏（严格模式一律精确执行，引擎已保证） |
| GPU 图案流式 | 仍是独立加速开关，**不进入**图案面板的「结果要求」；过程面板显示是否使用 GPU |

## 五、结果展示（图案侧）

| 列 | 内容 |
|---|---|
| 序号 | TopN 排名 |
| 距离 | 距起点距离（排序主键） |
| 坐标 | 窗口左上角 minX/minZ |
| 旋转 | 仅当取消「锁定方向」时显示（0°/90°/180°/270°） |
| 图案 | 迷你图案缩略图（可选，后续） |
| 操作 | 定位到地图（现有行为） |

## 六、实现要点（相对现有代码）

1. **不动引擎语义**：严格模式本来就是「完全匹配」；取消匹配要求等于维持现状，无引擎改动；
2. **UI**：图案模式下隐藏方案下拉/密度阈值行/算法选择；保留编辑器 + 方向 + 目标 + 停止选项；
3. **结果**：距离列已有内部数据（results 按距离排序），只需在表格/列表里显式展示；
4. **与设置重构联动**：`SearchPlan` 中图案相关字段保持现状（pattern、directionLocked），不新增字段；
5. **自检**：图案模式无方案下拉、阈值行隐藏、结果距离列存在、方向锁定与旋转结果正确。

## 七、后续可选（不在本轮）

* 如果以后用户确实需要"没那么像也行"，那才重新引入「接近匹配」，并且作为**独立功能入口**而不是开关；
* 图案模板/自定义保存：也放后续，不进本轮。

## 八、与排期的关系

* 3.9.11 的预设 UI **只做密度侧**；
* 图案侧本轮只做三件小事：模式切换时隐藏无关控件、方向文案澄清、结果显式显示距离；
* 因而图案侧工作量很小，可与预设 UI 同版完成。
