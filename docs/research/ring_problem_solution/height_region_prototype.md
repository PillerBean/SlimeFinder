# 高度可变刷怪面积：小规模原型结果

日期：2026-11-25  
脚本：`height_region_prototype.py` / `height_region_analysis.py`

## 模型

```text
平台：基岩底层，固定平面
有效面积：只按群系权重加权
球壳：24 ≤ 三维距离 ≤ 128
地图：384×384 方块
中心范围：128..255（128×128 = 16,384 个中心）
高度：0..128 逐方块枚举
```

这是研究原型，不是产品代码。

## 结果 1：有群系斑块的地图

合成权重图：

```text
背景 0.12
4 个大群系斑块 0.40 / 0.65 / 0.80 / 0.95
少量平滑噪声
```

精确枚举 129 个高度：

```text
全局最大有效面积：23,379.77
最佳高度：24
最佳中心：1 个
最大区域：1 个点 (164,129)
```

这说明：

```text
群系斑块形状不规则时，
最大有效面积可能是一个很尖锐的点，
区域输出在这种情况下就是“单点区域”。
```

候选快速法：

```text
圆盘上界 Top-100 就包含精确最优点
精确中心在上界中的排名：58 / 16384
Top-100 快速结果：与精确值一致
```

## 结果 2：完全均匀权重

```text
所有权重 = 1
```

连续几何预期：

```text
H=0..24 面积相同
```

但按离散方块计数：

```text
H=0       49,644
H=21      49,696  ← 最大
H=24      49,669
H=32      49,165
```

结果：

```text
全局最大有效面积：49,696
最佳高度：21（离散格点效应）
最大区域：16384 个中心全部相同
区域：128..255 × 128..255，一个连通区域
```

这是最重要的发现：

```text
连续模型下“0..24 等高带”在离散方块模型中会碎掉。
逐高度枚举时，最大高度可能不是 24，而是 21 这种格点相位造成的高度。
```

所以“等高带”必须用**实际的离散方块/群系权重**计算，不能只靠连续几何公式。

## 结果 3：快速候选法的召回

有群系斑块的例子：

| Top-K | 快速最大面积 | 与精确差 |
|---:|---:|---:|
| 100 | 23,379.77 | 0 |
| 500 | 23,379.77 | 0 |
| 2,000 | 23,379.77 | 0 |
| 5,000 | 23,379.77 | 0 |

均匀例子：

| Top-K | 快速最大面积 | 与精确差 |
|---:|---:|---:|
| 100 | 49,696 | 0 |
| 500 | 49,696 | 0 |

但注意：

```text
这次 Top-100 命中，不代表所有地图都能保证。
精确中心在圆盘上界中的排名是 58/16384；
换一张群系图可能排在 100 之后。
```

所以快速法需要：

```text
1. 更大的 K，或
2. 用 U(x,z) ≥ 当前最优 做严格剪枝，或
3. 多高度候选池合并
```

## 关键观察

```text
1. 平台固定基岩底层后，问题确实是“二维群系权重 × 高度”。
2. 连续面积等高带在离散方块下会碎掉，必须逐高度算。
3. 最大结果可能是点，也可能是巨大连通区域。
4. Top-K 圆盘上界在小图上很快，但不能假设永远 Top-100 命中。
5. 区域输出不是可选项；均匀权重时 16384 个中心全等。
```

## 下一步建议

先不要直接做全图产品，按这个顺序：

```text
P1 小图精确对照
  - 连续面积 vs 离散方块面积
  - 区域等价定义
  - Top-K 召回率随 K 的变化

P2 真实群系小区域
  - 取一个真实种子的小范围
  - 用同一套原型跑
  - 检查最大区域是否连续、高度是否唯一

P3 候选算法
  - 圆盘上界
  - 多个高度的候选池
  - U(x,z) ≥ best 的严格剪枝

P4 区域提取
  - 对最优高度做得分场
  - 连通域 + bbox/多边形
  - 代表点 + 高度带
```

## 结果 4：100 张随机群系图

每张图 384×384，随机 4～10 个矩形群系斑块。

### 高度范围定理

对任意非负群系权重：

```text
H > 24 的可刷怪水平区域
是 H=24 时圆盘的真子集
```

因为 H=24 时：

```text
内孔半径 = 0
外半径 = sqrt(128²-24²)
```

H>24 时：

```text
内孔仍为 0
外半径更小
```

所以：

```text
E(c,H>24) ≤ E(c,24)
```

**全局最优高度一定在 0～24 内。**  
高度搜索从 129 个值降到 25 个值。

### 最佳高度分布

```text
H=0   11 张
H=10   2 张
H=18   1 张
H=21   3 张
H=24  83 张
```

100/100 都在 0～24。

### 多高度候选池召回

对每张图，在 H=0 / 12 / 24 三个高度分别取 Top-50，合并候选：

```text
候选池平均大小：82
精确最优中心被包含：100/100
```

单高度精确得分图的 Top-10 也 100% 命中（但这是“已知最佳高度”后的结果，不能直接用于未知高度）。

圆盘上界 Top-100 在 30 张图上只有 93.3% 召回，说明：

```text
单一圆盘上界不够
多高度候选池明显更稳
```

### 区域

100 张随机斑块图的最大区域都是单点；  
完全均匀权重时最大区域是整个 128×128 中心域。

结论：

```text
结果既可能是单点，也可能是大区域；
输出必须同时支持“点”和“连通区域”。
```

## 推荐的最小快速算法

```text
1. 在 H=0 / 12 / 24 做三张粗分辨率得分图
2. 每个高度取 Top-K，合并候选
3. 对候选做径向直方图 + H=0..24 精确高度扫描
4. 取全局最优
5. 对达到最优的高度做一次得分场卷积 + 连通域
6. 输出区域、高度带、代表点
```

三张粗图 + 每个候选 25 个高度，比全图 ×129 小得多。

仍需验证：

```text
- 真实群系图上的三高度召回
- 不同 K 的召回率
- 近均匀群系下的大区域
- 高度带存在多个不连续区间的情况
```

用 Java 1.21.3、种子 `-8180004378910677489`，在环带参考点附近取 384×384 方块：

```text
x0=17415060, z0=28556300
群系权重 min=0.837, max=1.000, mean=0.986
```

精确枚举 H=0..24：

```text
最大有效面积：49,249.70
最佳高度：21
最佳中心：1 个
精确中心在圆盘上界中的排名：119 / 16384
```

多高度候选池：

```text
H=0/12/24 各 Top-10 联合：25 个候选，命中
H=0/12/24 各 Top-20 联合：45 个，命中
H=0/12/24 各 Top-50 联合：84 个，命中
```

说明：

```text
真实局部群系权重接近均匀（0.84～1.0），
最大结果同样是单点；
圆盘上界 Top-100 会漏，三高度联合池能找回。
```

## 目前证据的边界

```text
随机合成斑块图：100/100 三高度联合池命中
真实目标局部图：三高度联合池命中
但真实群系变化小，尚未覆盖“大面积等高区域”的真实案例
```

均匀权重时：

```text
最大区域 16,384 个中心
```

所以区域输出仍然必须保留，不能假定真实图总是单点。


### 重要发现：区域和点都必须支持

例如 `neworigin`：

```text
精确最大区域：13,384 个中心
```

如果只输出一个代表点，会严重低估结果结构。

而 `newref`：

```text
精确最大区域：1 个中心
```

只输出区域也会显得过度抽象。

所以输出结构必须是：

```text
最大区域（可能 1 个点，也可能很大）
+ 高度
+ 有效面积
+ 同面积高度带
```
