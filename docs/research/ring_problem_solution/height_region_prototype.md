# 高度可变刷怪面积：小规模原型结果

日期：2026-11-25  
脚本：`height_region_prototype.py` / `height_region_analysis.py`

## 模型

```text
平台：基岩底层，固定平面
有效面积：只按群系权重加权
球壳：24 ≤ 三维距离 ≤ 128
地图：384×384 方块
中心范围：128..255（128×128 = 16,384 个中心）
高度：0..128 逐方块枚举
```

这是研究原型，不是产品代码。

## 结果 1：有群系斑块的地图

合成权重图：

```text
背景 0.12
4 个大群系斑块 0.40 / 0.65 / 0.80 / 0.95
少量平滑噪声
```

精确枚举 129 个高度：

```text
全局最大有效面积：23,379.77
最佳高度：24
最佳中心：1 个
最大区域：1 个点 (164,129)
```

这说明：

```text
群系斑块形状不规则时，
最大有效面积可能是一个很尖锐的点，
区域输出在这种情况下就是“单点区域”。
```

候选快速法：

```text
圆盘上界 Top-100 就包含精确最优点
精确中心在上界中的排名：58 / 16384
Top-100 快速结果：与精确值一致
```

## 结果 2：完全均匀权重

```text
所有权重 = 1
```

连续几何预期：

```text
H=0..24 面积相同
```

但按离散方块计数：

```text
H=0       49,644
H=21      49,696  ← 最大
H=24      49,669
H=32      49,165
```

结果：

```text
全局最大有效面积：49,696
最佳高度：21（离散格点效应）
最大区域：16384 个中心全部相同
区域：128..255 × 128..255，一个连通区域
```

这是最重要的发现：

```text
连续模型下“0..24 等高带”在离散方块模型中会碎掉。
逐高度枚举时，最大高度可能不是 24，而是 21 这种格点相位造成的高度。
```

所以“等高带”必须用**实际的离散方块/群系权重**计算，不能只靠连续几何公式。

## 结果 3：快速候选法的召回

有群系斑块的例子：

| Top-K | 快速最大面积 | 与精确差 |
|---:|---:|---:|
| 100 | 23,379.77 | 0 |
| 500 | 23,379.77 | 0 |
| 2,000 | 23,379.77 | 0 |
| 5,000 | 23,379.77 | 0 |

均匀例子：

| Top-K | 快速最大面积 | 与精确差 |
|---:|---:|---:|
| 100 | 49,696 | 0 |
| 500 | 49,696 | 0 |

但注意：

```text
这次 Top-100 命中，不代表所有地图都能保证。
精确中心在圆盘上界中的排名是 58/16384；
换一张群系图可能排在 100 之后。
```

所以快速法需要：

```text
1. 更大的 K，或
2. 用 U(x,z) ≥ 当前最优 做严格剪枝，或
3. 多高度候选池合并
```

## 关键观察

```text
1. 平台固定基岩底层后，问题确实是“二维群系权重 × 高度”。
2. 连续面积等高带在离散方块下会碎掉，必须逐高度算。
3. 最大结果可能是点，也可能是巨大连通区域。
4. Top-K 圆盘上界在小图上很快，但不能假设永远 Top-100 命中。
5. 区域输出不是可选项；均匀权重时 16384 个中心全等。
```

## 下一步建议

先不要直接做全图产品，按这个顺序：

```text
P1 小图精确对照
  - 连续面积 vs 离散方块面积
  - 区域等价定义
  - Top-K 召回率随 K 的变化

P2 真实群系小区域
  - 取一个真实种子的小范围
  - 用同一套原型跑
  - 检查最大区域是否连续、高度是否唯一

P3 候选算法
  - 圆盘上界
  - 多个高度的候选池
  - U(x,z) ≥ best 的严格剪枝

P4 区域提取
  - 对最优高度做得分场
  - 连通域 + bbox/多边形
  - 代表点 + 高度带
```
