## 与旧基线比较

旧方形加权基线（参考点）：

```text
newseed 14595.9
seed0   14324.5
```

本次候选级新结果：

```text
newseed 14451.7  (-1.0%)
seed0   14244.3  (-0.6%)
```

差异主要来自：

```text
1. 候选中心只取 chunk 中心，没有块级偏移精修
2. 群系权重按 chunk 中心近似，不是逐方块
3. 方形预筛不是高度专用预筛
```

因此这不是“高度模型退化”，而是候选级测试的精度上限。

## 关键观察

```text
1. 高度维度本身非常便宜：
   4000 种子 1 秒，20000 种子 5 秒。
2. 全图瓶颈仍是方形 GPU 预筛。
3. 扩大候选到 20000 没有改善第一名。
4. 候选级结果仍低于旧方形加权基线约 0.5%–1%。
5. 需要真正的高度专用全图预筛，或块级精修，才能判断质量。
```

## 局限

```text
- 不是全图精确枚举
- 没有全图区域提取
- 没有块级 16×16 偏移精修
- 群系权重按 chunk 中心近似
- 只测了两个种子
```

## 下一步

```text
A. 高度专用候选池
   在 H=0/12/24 做三张全图预筛，而不是一张方形预筛。

B. 顶部候选块级精修
   对 Top-N 的中心做 16×16 偏移 + 逐方块群系权重。

C. 区域提取
   对最优高度做得分场，得到点或大连通区域。

D. 与旧方形基线做同精度对照
   否则 0.5%–1% 的差距无法归因。
```
