# Ring Coverage Counterexample Problem

状态：开放问题，未解决  
用途：向社区提交的正式问题说明  
范围：方形密度预筛 + 环形覆盖最优

---

## 1. 符号

| 符号 | 含义 |
|---|---|
| `N` | 地图边长，单位为 chunk |
| `p` | 每个 chunk 为史莱姆区块的独立概率，默认 `0.1` |
| `X` | `N×N` 二值矩阵，`X(i,j)∈{0,1}` |
| `Ω` | chunk 坐标集合 `{0..N-1}²` |
| `D` | block 坐标集合 `{0..16N-1}²` |
| `r` | 环带内半径，block，默认 `24` |
| `R` | 环带外半径，block，默认 `128` |
| `g` | 方形窗口边长，chunk，默认 `15` |
| `K` | 方形预筛种子数，默认 `4000` |
| `c` | 候选中心，block 坐标 `(x,z)∈D` |
| `w(i,j,c)` | chunk `(i,j)` 对中心 `c` 的环带覆盖格数 |
| `C_X(c)` | 中心 `c` 的环形覆盖 |
| `S_X(a,b)` | chunk `(a,b)` 的方形分数 |
| `E_K(X)` | 算法实际评估的中心集合 |
| `A(X)` | 算法输出中心 |
| `M(X)` | 全局最大环形覆盖 |

---

## 2. 环形覆盖

chunk `(i,j)` 的 block 矩形：

```text
Rect(i,j) = [16i, 16i+15] × [16j, 16j+15]
```

对中心 `c=(x,z)`，定义：

```text
w(i,j,c) =
  count {
    (u,v) ∈ Rect(i,j)
    :
    r² ≤ (u-x)² + (v-z)² ≤ R²
  }
```

因此：

```text
w(i,j,c) ∈ {0,1,...,256}
```

环形覆盖：

```text
C_X(c) = Σ_{(i,j)∈Ω} X(i,j) · w(i,j,c)
```

全局最优值：

```text
M(X) = max_{c∈D} C_X(c)
```

---

## 3. 方形分数

chunk `(a,b)` 的 `g×g` 窗口：

```text
W(a,b) =
  { (i,j) ∈ Ω :
    |i-a| ≤ (g-1)/2,
    |j-b| ≤ (g-1)/2 }
```

方形分数：

```text
S_X(a,b) = Σ_{(i,j)∈W(a,b)} X(i,j)
```

默认：

```text
g = 15
(g-1)/2 = 7
```

## 4. 候选生成算法

### 4.1 种子

```text
TopK(X) =
 按 S_X(a,b) 从大到小取 K 个 chunk
 并列时按 (b,a) 字典序决胜
```

### 4.2 精修集合

对每个种子 chunk `q=(a,b)`：

```text
B(q) = { (16a+u, 16b+v) : 0≤u,v<16 }
```

即该 chunk 内全部 256 个 block 中心。

取 `TopK` 中方形分数最高的前 8 个 chunk，记集合 `P8(X)`。

对每个 `q∈P8(X)`，加入其周围 `3×3` chunk 邻域：

```text
N3(q) = { (i,j) : |i-a|≤1, |j-b|≤1 }
```

最终评估集合：

```text
E_K(X) =
  ( ∪_{q∈TopK(X)} B(q) )
  ∪
  ( ∪_{q∈P8(X)} ∪_{s∈N3(q)} B(s) )
```

### 4.3 输出

```text
A(X) ∈ argmax_{c∈E_K(X)} C_X(c)
```

并列时只要求覆盖值相等。

### 4.4 失败

```text
F(X) = 1  ⇔  C_X(A(X)) < M(X)
```

## 6. 问题

### Q1：反例存在性

是否存在有限的 `N,K` 和配置 `X`，使：

```text
F(X) = 1
```

？

若存在，给出：

```text
最小 N
最小 K
显式 X
```

若不存在，证明：

```text
∀X, C_X(A(X)) = M(X)
```

或给出反例搜索的完备证书。

### Q2：小网格精确计数

对固定 `N`：

```text
CountFail(N,K) =
  | { X∈{0,1}^{N×N} : F(X)=1 } |
```

求：

```text
N=4
N=5
K=1,2,8
```

给出计数或完整枚举程序/证书。

### Q3：p=0.1 的失败质量

对反例集合：

```text
Fail(N,K) = { X : F(X)=1 }
```

定义：

```text
P_fail(N,K,p) =
  Σ_{X∈Fail(N,K)}
    p^{|X|} (1-p)^{N²-|X|}
```

其中：

```text
|X| = X 中 1 的个数
```

求：

```text
P_fail(N,K,0.1)
```

至少给出上下界。

### Q4：实际参数的概率

对：

```text
N=3,750,000
K=4000
p=0.1
```

求：

```text
P_fail(N,K,p)
```

或给出可证明上界：

```text
P_fail ≤ 10^{-s}
```

并给出 `s`。

## 7. 已知结构约束

对中心在 chunk 中心的情况：

```text
环带 chunk 总数        = 188
方形窗口内环带 chunk   = 184
方形窗口外环带 chunk   = 4

方形窗口 chunk 总数    = 225
方形窗口内环带 chunk   = 184
内圈禁区 chunk         = 9
环带外方角 chunk       = 32
```

因此：

```text
高 C_X 通常伴随高 S_X
```

任何反例必须解决：

```text
目标点 C_X 高
目标点 S_X 低到进不了 TopK
目标点不在 P8 的 3×3 邻域
且目标点仍是全局最优
```

## 9. 提交给社区的回答格式

优先接受：

```text
1. 一个显式 X（小矩阵/二进制串）满足 F(X)=1
2. 一个 SAT/CP-SAT 模型及 UNSAT 证明
3. Q2 的精确计数
4. Q3/Q4 的可证明上界
5. 对 Q1 的“无反例”结构性证明
```

不接受：

```text
仅用参考点尾概率代替 F(X) 的统计
未枚举配置的“几乎不可能”结论
```
