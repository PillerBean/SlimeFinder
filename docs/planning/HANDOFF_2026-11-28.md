## 3. 已完成的主要功能

- 命令终端：`setting`、多级 Tab、格式提示、search/result/cache/page/map/pattern/afk 分支、旧命令迁移。
- 多语言：1456 keys × zh-CN/zh-TW/en-US，占位符一致。
- 环形 k3 上界复核档；不宣称全局最优。
- 高度可变有效面积：`HeightRefiner`，H=0..24，块级群系权重、16×16 邻域；`AfkDialog` 自动重排，新增“高度 H / 有效面积 / 绝对 Y”列；绝对 Y=afkBaseY+H。
- Bedrock 群系：独立 `cubiomes-bedrock`（MIT，`third_party/cubiomes-bedrock`），独立 helper，不与 Java cubiomes 混链。
- Bedrock 版本选择：主窗口顶部独立下拉；按算法分组压缩为 16 组（1.0、1.1、1.2、1.4-1.6、1.7-1.13、1.14、1.16-1.17.30、1.18…26.60）。
- Bedrock 河流过滤：`BedrockRiverFilter` 调用 helper，移除 river/frozen_river；需要 seed；helper 在包内。
- 缓存导入重复点击崩溃已修：join 已完成 worker、完成后禁用“开始导入”。
- 缓存地图等比缩放；环形四档改名（撒点抽取/预筛精修/环带上界复核/暴力遍布）。
- 缓存小范围 P0 直读：range≤band 时直接 `opt.cache`，不套 banded；真实 8192 pack 测试 direct 124.8ms、banded 176.8ms、plain 1228ms。
- 真实缓存探针：`tools/bench/cache_real_probe.cpp`。

## 4. 关键约束与设计决定

- 2D 方形 GPU 预筛是速度设计，**不要因不精确擅自移除**；全图约 217–232s。
- k3 是候选级上界复核，不是全局最优证明。
- H>24 由 H=24 支配；高度只扫 0..24。
- Bedrock 1.18+ 有上游哈希校验；1.18 前用 Bedrock 分层生成器，Java 哈希不适用，不能当失败。
- 公共标识符用下划线，不用点。
- 不伪造库中不存在的版本 1.3/1.15。

建议：
1. `AfkPlanOptions` 已有 `const CacheManager* cache`。

5. 对比 plain/k3 结果与耗时，验证边界不丢。

### P2 搜索页 A/B/C 重排

目标：
- A 搜索方式：撒点抽取、预筛精修、环带上界复核、暴力遍布。

现状：`minDensity` 仍由 `densityPanel/densityAdvanced` 管理；目标数量/模拟距离/图案混在搜索参数区。需迁控件、重建布局、更新 `updateSearchShapeEnabled/applyResultConflicts` 和 GUI 自检、三语。
