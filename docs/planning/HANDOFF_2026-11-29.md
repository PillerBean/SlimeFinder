## 3. 本轮完成内容

### P1：环形/k3 预筛缓存化

- 新增 `src/core/CachePrescan.h/.cpp` → `slime::cachePrescanSeeds`（Qt 无关，`slime_core`）：
  缓存位图完整覆盖区域时，按行流式 + 滑动窗口在 CPU 上复刻 GPU `prescanDensitySeeds` 的
  窗口/阈值/分带/topPerBand/排序/去重/截断语义；多 range 遮蔽有确定性慢路径；负坐标 int64 安全。
- `MainWindowRingMap.inc`：`RingSearchResult::cachePrescanUsed`；`ringCache` 按值捕获进 worker；
  **集成取舍（实测驱动）**：有 GPU 时仍走 GPU 预筛（实测生产参数快 1.5~3.5×），
  GPU 不可用/失败且缓存完整覆盖时用缓存预筛兜底，两路都不可用才回退快速抽样。
- 验证：单测 `[39] testCachePrescanSeeds`；对拍探针 `build\k3_prescan_parity_probe.exe`（GPU vs 缓存
  位图，无截断配置逐条一致）与 `build\cache_prescan_compare.exe`（端到端 k3 规划对照 + 真实缓存模式）。
- 文档：`docs/planning/k3_cache_prescan.md`（含性能数据、平局差异、复现命令）。

### P2：搜索页 A/B/C 重排

- 三个顶层分组：**A 搜索方式 / B 结果要求 / C 执行设置**；原有 6 个分组作为子分组保留。
- A：环形=四档扫描方式 combo（从环形选项迁出）；图案/正方形=原「匹配方式」算法块。
- B：搜索范围、搜索模式与方案、区域形状、**最低密度/忽略阈值改常显**（关键修复）、
  目标数量/达到即停/智能范围合入「停止与数量」；环形内外半径从设置页迁到 B（默认 24/128）。
- C：性能设置 + RAM 预算只读摘要 + 缓存管理。
- 新增「按群系权重排序（Java）」开关（默认勾选 = 旧行为；关=纯方块数口径）。
- i18n 新增/变更 key 三语同步（1457 → 1468）；修复环形扫描四档语言刷新错位。
- GUI 自检：A/B/C 顺序、控件归属、可见性矩阵、横滚动回归断言。

## 4. 关键约束与设计决定（新增/保留）

- 2D 方形 GPU 预筛不要因不精确移除；**预筛来源按实测选择**：GPU 优先、缓存预筛兜底
  （若有 AVX2 优化让 CPU 位图预筛稳定快于 GPU，再评估改为缓存优先，见 k3 文档 §7）。
- k3 是候选级上界复核，不宣称全局最优；GPU/缓存两条路径在 `topPerBand` 边界 count 平局上
  取舍不同（GPU 本身未定义、同输入多次运行种子数不稳定），k3 最终最优候选一致。
- H>24 由 H=24 支配；高度只扫 0..24。
- Bedrock 1.18+ 有上游哈希校验；1.18 前 Bedrock 分层生成器与 Java 哈希不适用。
- 公共标识符用下划线，不用点；不伪造库中不存在的版本 1.3/1.15。
- 环形内外半径现在只在搜索页 B 组出现（设置页已移除，`settings.ringInner/ringOuter` 字段保留）。
