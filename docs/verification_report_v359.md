# SlimeFinder v3.5.9 验证报告

日期：2026-10-18　版本：v3.5.9（正式版，历史 56 条 / 正式版 12 个）

## 一、本版改动

1. **严格 1 格统计（本轮核心）**：环形/加权结果不再用粗扫估值，`AfkPlanner::measureExact(blockX, blockZ, opt, isSlime)` 逐格遍历环带（1/16 区块 = 游戏最小生成格），给出有效格、有效区块、总权重、覆盖率。列表前 8 名用「1:4 群系网格 + 逐格判定」严格重算，其余沿用粗扫值并在状态栏注明近似。
2. **统计口径**：世界倒数第二层 y（1.18 前 y=1，之后 y=-63），状态栏显式标注；全环带统一。
3. **排版重排**：搜索模式组内按 区域形状 → 图案/密度 → 各自选项 排列；环形下常驻参数只保留「最小密度」，其余隐藏；判定算法与区域形状解耦，两组互不影响。
4. **速度**：小范围（窗口 ≤2048 格）自动走精确路径保质量；粗扫内层去分支（可向量化）、4 套卷积核、按区块去重、M 自适应（≤40000 区块用 200，否则 48）。

## 五、已知限制

- 群系权重与群系判定按 1:4（游戏群系最小 4 格 ⇒ 该精度下每格精确）；更细的 1:1 群系不参与统计。
- 只有前 8 名做严格逐格重算，其余候选沿用 planner 的粗扫近似值。
- 环形范围上限 4096×4096 区块；更大的范围需要缩小或分块。
- 大范围环形粗扫是近似（小范围会自动走精确路径），基岩版不提供群系权重。
- 结果列表最多显示 500 条。
