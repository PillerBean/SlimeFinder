# SlimeFinder v3.11.0

## 多语言与 UI 文本隔离

- 全部用户可见文案移到外部语言包：
  - `assets/i18n/zh-CN.json`
  - `assets/i18n/en-US.json`
- 代码只保留 key，通过 `slime::ui::t("ui.<hash>")` 取文案；
- 旧的 `UiStrings` 翻译表也迁移到 `assets/i18n/legacy-zh-en.json`；
- 语言包随安装包发布，可在不重新编译的情况下替换/新增语言；
- 新增 `scripts/check_ui_text.py` 做 key 完整性与硬编码检查。

## 说明

- 界面语言目前仍为简体中文 / English 两种，切换后重启生效；
- 新增语种只需增加 `assets/i18n/<lang>.json` 并接入语言选择（后续小版本）。
