# 匿名统计与隐私说明

SlimeFinder 的匿名使用统计**默认关闭**。只有用户在「帮助 → 匿名统计（帮助改进）」里主动勾选并保存后，程序才会发送统计事件。

## 发送什么

用户主动开启后，发送与改进程序有关的信息：

- 程序版本、更新通道、界面语言；
- Windows 平台名称、架构；
- CPU 型号、逻辑线程数、内存档位（GB）；
- GPU 名称、GPU 是否可用；
- 游戏平台（Java / 基岩）；
- **世界种子**；
- 搜索设置：范围、起点、模式、算法、环形扫描模式、网格/阈值/目标数量、分层/采样参数、GPU 开关；
- 结果：数量、命中总数、最佳覆盖率/密度、前 5 条结果坐标；
- 速度：总耗时、扫描/匹配耗时、扫描区块数、区块/秒；
- 是否取消、是否提前停止、是否使用 GPU；
- 缓存构建的范围、耗时、条目档位、是否达到预算。

## 不发送什么

- 存档路径、缓存路径、日志内容；
- 账号、设备 ID、安装 ID、持久标识；
- 服务端不保存 IP 地址。

## 服务端

- 接收端为 Cloudflare Worker + D1，代码在 `telemetry/worker.js`；
- 部署步骤见 `telemetry/README.md`；
- 事件只写入白名单字段，不保存原始请求头/IP。

## 如何开启/关闭

- 帮助 → 匿名统计（帮助改进）；
- 勾选/取消“我自愿开启匿名统计”并保存；
- 设置保存在程序目录 `telemetry.json`，可随时删除该文件恢复默认关闭。
