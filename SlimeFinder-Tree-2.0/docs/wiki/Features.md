# 功能说明

## 版本支持

| 版本 | 判定 | 范围上限 |
|---|---|---|
| Java 版 | 与参考实现逐位一致 | ±1,875,000 区块（世界边界） |
| 基岩版 | 基于 MT19937 参考算法 | ±131,072 区块（约 ±2,097,152 方块，float32 0.25 精度边界） |

## 搜索模式

### 密度模式

按 g×g 窗口内的史莱姆数量/密度筛选：

- **阈值匹配**：找密度 ≥ 最小密度的窗口，可配合「找够就停」；
- **最优 N 个**：忽略阈值，按密度排序取前 N 个（大范围会分块并归并）；
- **提前停止**：找够目标数量即停；
- **智能范围**：由近及远扩展搜索（部分算法下更快，部分场景会略慢，可对比尝试）；
- **分层 / 采样**：分层为近似加速（结果可能与精确不同），采样为快速估算（可能漏检）。

### 图案模式

在图案编辑器里用左键画绿、右键标灰（忽略）：

- 支持 2×2、3×3 边框、单格、自定义大小；
- 支持旋转匹配（方向锁定可关）；
- 适合「特定角落/形状才刷史莱姆」的刷怪点规划。

### 环形模式

规划 AFK 挂机点：以中心为基准，按环带覆盖一定范围，输出候选挂机位置；
适合长期挂机刷史莱姆。

## 加速与辅助

- **GPU 加速**：密度/图案流式匹配，自动探测、失败回退 CPU；
- **历史缓存**：同一范围重复搜索时复用已判定位图；
- **分块搜索**：超大范围自动切块，内存有界；
- **检查更新**：GitHub 官方 / 自动镜像测速 / 蓝奏云网盘备用。

## 界面

- 深色 / 浅色主题；
- 内置使用教程、命令终端、日志与进度分类面板；
- 结果可排序、复制为命令、导出文件。
