# 常见问题

### 杀毒软件报毒 / 被拦截？

程序未做代码签名，部分杀软会对新发布的小众 exe 误报。可：
- 从 GitHub Releases 官方页面下载，核对 `SHA256SUMS`；
- 将程序目录加入杀软白名单；
- 不要从第三方转载站下载。

### GPU 加速开启后没变化 / 不可用？

- 更新显卡驱动，确认支持 OpenCL；
- 小范围或命中很少时 GPU 固定开销高，可能不如 CPU；
- 驱动异常时程序会自动回退 CPU，可关闭 GPU 后重试；
- AMD 显卡可尝试「图案 GPU 流式」。

### 检查更新提示失败？

- 检查更新依赖系统自带的 `curl.exe`（Windows 10 1803+）；
- 官方不可达时选「自动」会测速镜像；仍失败可点「打开网盘下载页（备用）」；
- 当前没有比本机更新的正式版时会提示“已是最新”。

### 搜索很慢？

- 大范围会分块并提示预计耗时，属正常现象；
- 开启「提前停止」通常最快；命中极少时用「最优 N 个」；
- 重复搜索同一范围建议启用缓存。

### 旧版本还能下载吗？

可以。Releases 页面保留了历史版本（`-archive` tag，二进制归档）。
老版本源码未保留，README/更新历史里有各版本变更记录。

### 如何反馈问题？

到 <https://github.com/PillerBean/SlimeFinder/issues> 新建 Issue，附上：
- 版本号、系统、显卡（如涉及 GPU）；
- 复现步骤与结果；
- 必要时附 `logs/` 下的日志。
