# GPU 与性能

## 如何开启

「设置 → 性能 → 启用 GPU 加速」（或主界面性能区勾选）。

- 首次启用会探测 OpenCL 设备并测一次吞吐率；
- 可在「设置 → 性能」把 GPU 设为默认启用；
- 无可用 OpenCL 驱动时会自动回退 CPU。

## 实测参考（本机 Ryzen 5 5600 + RX 6750 GRE 10GB）

| 场景 | CPU（12 线程） | GPU |
|---|---|---|
| 密度 8k² g5 阈值 0.3 | 19 ms | 4~4.4 ms |
| 密度 16k² g5 | 71 ms | 10~10.5 ms |
| 密度 20k² g8 | 138 ms | 9~11 ms |
| 密度 70k² 分块 | 1944 ms | 68 ms（约 722 亿区块/秒） |
| 图案/环形 100k² | 约 2.2~2.7 s | 127~160 ms（约 625~811 亿区块/秒） |

完整数据与社区归一化对照见仓库 `docs/community_benchmark_reference.md`。

## 可选开关

- **图案 GPU 流式**：AMD 实测约 2~18 倍提速；NVIDIA/Intel 未验证，可先小范围试跑；
- **结果自优化（密度提前停止）**：倾斜/角落起点收益明显，默认关闭，行为与旧版一致。

## 故障排查

1. **GPU 不可用**：更新显卡驱动（确保 OpenCL 支持）；极老的核显/驱动可能不支持；
2. **GPU 反而慢**：小范围/命中很少时 GPU 固定开销占比高，可关闭 GPU；
3. **程序占用高**：在设置里限制 CPU/GPU 占用率上限；
4. **搜索结果与 CPU 不一致**：GPU 与 CPU 判定逐位一致；如不一致请反馈并附日志。

提示：GPU 优化建立在「判定次数换吞吐」上，范围越大越能体现优势。
